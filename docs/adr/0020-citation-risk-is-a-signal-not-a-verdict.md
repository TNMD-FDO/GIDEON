# Citation risk is a signal, not a verdict: no green state, worst signal wins, only code and an official list set `negative`, a model sets `caution` at most

GIDEON shows a **risk state** beside every cited case — `negative`, `caution`, or `unchecked` — computed per index generation from GIDEON's **own citation graph** (edges parsed from the corpus text at ingest and resolved to cases, i.e. clusters; CourtListener's citation map is an agreement check, never the record). `negative` is set only by deterministic code — bounded patterns over the citing sentence, in a majority-body section, from a court that can bind the cited case — or by the Library of Congress table of Supreme Court decisions the Court has explicitly overruled. `caution` is set by any other court's explicit negative language, by a statute section amended after the opinion's decision date, or — when the off-by-default enrichment job is on — by the generator's classification of a citing sentence. `unchecked` renders nothing inline and says *"no negative citing language found … not checked: …"* in the chip panel. A case's state is its worst signal. There is no green, no check mark, and no "good law" anywhere GIDEON renders (CI-tested), no composite score, no tunable weights, and no ranking effect. Greenfield-spec ticket 17, Aug 2026.

**Rejected:** draft 2's composite risk score weighted by court level and recency — a number nobody can audit, tuned by nobody, that reads as a verdict; letting the LLM job set `negative` — a model's word would carry a machine's authority for the one state that makes an attorney drop a case (ADR-0006's rule, applied to treatment); counting every section — a dissent's "I would overrule" is not treatment, so non-holding language is listed in the panel and never sets a state; importing CourtListener's map as the edge record — no spans, no way to read the citing sentence, and two resolution rules for one edge; a hand-labeled treatment classifier (100–300 attorney-hours) and commercial citator integration — both out of scope from charting.

**Consequences:** open data carries no treatment at all (eyecite parses no subsequent history, CourtListener's graph is structural, and the finer labels — distinguished, criticized — have no open training set), so recall is deliberately low and the footer says so on every answer; the pattern signal is `on` only after its precision clears 0.95 on CaseHOLD's `overruling` set, and its recall is measured against the Congress.gov table on every generation; the state belongs to the case (cluster) while the section label belongs to the citing opinion; a case overruled in part still ranks on relevance — the label, not the ranking, carries the warning; the graph's two named tools return the citing-span chunks, so a treatment claim in an answer is always a quotation the verification gate checks; Westlaw or Lexis validation stays the human step, and the product says so in the footer of every Research answer.
