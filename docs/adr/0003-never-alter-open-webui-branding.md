# Never alter Open WebUI branding

Open WebUI's license (custom BSD-3, clause 4) prohibits altering, removing, obscuring, or replacing "Open WebUI" branding except for deployments with at most 50 end users in any rolling 30-day period, or with written permission or an enterprise license. GIDEON sits at that threshold and receiving offices may not, so we adopt a hard rule rather than relying on the exemption: **no deployment of GIDEON, at any office or user count, alters Open WebUI branding.** The only sanctioned customization is `WEBUI_NAME=GIDEON`, which the software itself renders as "GIDEON (Open WebUI)"; logos, favicons, and other identifiers stay stock. This rule ships in the spec and install docs so receiving offices inherit it, and a scoped counsel memo confirmed the redistribution posture ahead of the first external release — "nothing in the underlying law or licenses blocks this", 2026-08-28 (greenfield-spec map, tickets 05 and 26, Aug 2026).
