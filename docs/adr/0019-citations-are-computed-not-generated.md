# Citations are computed, not generated: the model writes source tags, code renders every citation and pincite from the record, the verification gate only removes, and the Research service that runs it owns the whole turn

In GIDEON's Research branch the generator never writes a citation string or a page number. It writes prose, **source tags** (`[SRC:n]`, n = a hit in the turn's final set), and verbatim quotations; **code** renders every citation from the record — name, reporter cite, court, year, section and authority-tier labels — and computes the pincite as the quoted span's offsets intersected with the document's `reporter_page` anchors (ADR-0013, ADR-0014). The **verification gate** then checks, in deterministic code and never by a model, that every tag resolves, every quotation is a verbatim substring of the passage it tags, no citation was written by the model, and section attribution is rendered; what fails is held, repaired once by a bounded generator call against the same evidence, and otherwise **removed** — the gate never inserts legal content. All of this runs inside one **Research service** endpoint that owns the turn (retrieve → prompt → generate → verify → render); the Open WebUI Pipe is transport, the service is the only caller of the generator on Research's behalf, and the eval harness calls the same endpoint, so there is no Research code path that returns generator text unverified. This is the no-model-arithmetic rule (ADR-0006) applied to citations: a reporter cite, a year, and a pincite are computed facts, so code produces them or nobody does. Greenfield-spec ticket 16, Aug 2026; evidence in `docs/research/vllm-structured-output-with-reasoning.md` and `docs/research/owui-citation-rendering.md` (branches of the same names).

**Rejected:** the model writing citations that the gate then checks (draft 1's literal pipeline) — a wrong page, year, or reporter is the commonest real citation error and checking it is strictly weaker than never producing it; a decoding grammar as the enforcement (it can only force a *valid* tag, so a model reaching for a hit that does not exist is steered into one it did not mean, invisible to any check — the grammar ships off and is an experiment); whole-answer regeneration on a failure (verified paragraphs vanish and a different answer appears) and stream-then-fix (a fabrication reaches the screen); a Pipe that orchestrates retrieval, engine, and a verify endpoint itself (the gate becomes skippable by construction, and the eval would have to re-implement the path); NLI entailment or the generator judging its own claims in v1 (no legal-text evidence, and a model checking a model — deferred behind the span-grounding metric with a named trigger); Self-RAG-style generation-side re-retrieval (ADR-0016, ADR-0018).

**Consequences:** citation precision and pincite precision are true by construction and still measured on every eval run; the answer reads in house style (full cite on first mention, code-generated short form after, labels as parentheticals) rather than the model's; a case quoted inside a retrieved passage is citable only if it is itself retrieved; prior turns are fed back to the model with citation strings stripped to case names; the model's reasoning text is never rendered or stored; the answer streams under a paragraph hold so verified text never moves and unverified text never shows; every fixed text the gate emits is a versioned product artifact with no site key; and the Research service is the contract ticket 20 designs the service inventory around.
