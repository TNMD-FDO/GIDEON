# CC0 public-domain dedication for GIDEON's own code

Code written by FPDO staff on duty is, we believe, a work of the United States Government (17 U.S.C. §105) and so carries no US copyright; GIDEON's own code is therefore released with the government-work notice plus a CC0-1.0 worldwide dedication (the 18F/GSA pattern), with contributions accepted only under the same dedication. Chosen over Apache-2.0 (a government work cannot grant what it does not hold; only meaningful for outside contributions) and over "no license" (every receiving office would have to ask). The contribution line matters because Community Defender Organizations are nonprofits whose staff *are* copyright holders. Third-party components (Open WebUI, engines, models) keep their own licenses. Accepted 2026-08-28 on counsel's answer — "nothing in the underlying law or licenses blocks this" — confirming the §105 reading and that no judiciary policy restricts public release (greenfield-spec ticket 26); a Community Defender Organization reply on the contribution term is still pending and, if it objects, amends only that line.
