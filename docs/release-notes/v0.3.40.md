## What is new

Nothing you can see in the chat has changed. The nightly backup now also keeps
the documents GIDEON stores, so a restore brings them back with everything else;
a restore only ever adds documents and never removes one. Installing it restarts
only the monitoring page, as every upgrade does; nobody is signed out.
