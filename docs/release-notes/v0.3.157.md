# GIDEON v0.3.157

Template: 3

## What is new

Nothing user-visible. The build check that the opinion reader splits court
opinions correctly gains a fourth test: every page number printed in an
opinion's source must still be found after the reader has processed it, so a
page number the reader loses fails the check instead of passing unseen. The
same check now also reports how well the source's own page maps agree with the
reader's page numbers, as a figure that never fails the check.

## What was bumped

No pin moved since v0.3.156.

## Coverage
