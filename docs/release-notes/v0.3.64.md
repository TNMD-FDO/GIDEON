## What is new

Nothing you can see in the chat has changed. GIDEON and the office's transcription
app now share the server by written rules: either can be installed first, each
keeps working without the other, and neither removes what the other set up. The
code that follows these rules arrives in later releases. No service an office runs
is restarted except the monitoring dashboard.
