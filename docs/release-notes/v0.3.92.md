# GIDEON v0.3.92

Template: 3

## What is new

Nothing you can see in the chat has changed. Before GIDEON is installed or
upgraded, it checks that the network ports it needs are free or already used by
GIDEON itself. That check used to recognise GIDEON's web front door by its name,
so another application on the server with a similar name could pass for GIDEON's.
It now recognises GIDEON's own parts by the label GIDEON gives them, and when
another application holds one of the ports it names that application, so the
person installing can see what is in the way. Upgrading to this release restarts
the monitoring dashboards for about a minute.
