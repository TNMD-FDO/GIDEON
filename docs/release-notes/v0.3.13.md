# GIDEON v0.3.13

Template: 3

## What is new

The monitoring dashboards no longer reach outside the office when someone uses
them. Every account now shows the default profile image, and Grafana no longer
fetches pictures from Gravatar. Snapshots can no longer be published to Grafana
Labs' public host, but snapshots kept on the box still work. Plugins can no
longer be installed from the catalog, and the news feed is gone. The Plugins
page can still show the catalog's listing where the office firewall allows it.
Even then, it installs nothing.

## What was bumped

No pin moved since v0.3.12.
