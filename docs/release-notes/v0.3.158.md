# GIDEON v0.3.158

Template: 3

## What is new

Nothing user-visible. The nightly check that sends General a small set of
test questions no longer fails when the model, on one try, declines a question
it is expected to answer: that question is asked again, up to three times in
all, and the check fails only if every try declines. The record counts the
tries and keeps the first try's reading, so a decline stays visible without
paging anyone.

## What was bumped

No pin moved since v0.3.157.

## Coverage
