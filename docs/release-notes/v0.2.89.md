## What is new

Nothing you can see in the chat has changed. An upgrade no longer stops before
it starts when the release being left judges a piece of the server's setup as
out of date: it reports that piece as a warning and carries on, and the new
release sets it up and checks it before anything is switched over. A real
problem with the office's own services still stops the upgrade before it
changes anything, as before.
