# GIDEON v0.3.93

Template: 3

## What is new

Nothing you can see in the chat has changed. Before GIDEON is installed or
upgraded, its server check now looks at how much memory is free on each graphics
card and whether the AI models GIDEON is about to start will fit there, beside
what the other application on the server already uses. When a card is too full,
the check stops and says which card, how much is free, and who holds the rest,
where before a model simply failed to start partway through. The memory GIDEON
promises to leave for the other application is now written into the release and
checked by its tests. Upgrading to this release restarts the monitoring
dashboards for about a minute.
