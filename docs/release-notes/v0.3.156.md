## What is new

Nothing user-visible. The operator's install and upgrade guide gains a section
for a server that loses a memory module or a graphics card: what the update's
hardware check means when it refuses, what keeps running meanwhile and at what
risk, what to read to confirm the loss, the choice between a repair in an
announced window and a smaller hardware profile, and who decides. The quick
reference card and the guide to the pages point to it.
