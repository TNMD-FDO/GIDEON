## What is new

Nothing you can see in the chat has changed. When the box's check of the chat
model finds a problem with the chat page, the fix it prints now says what the
apply step really does for the chat page: it connects the page to General's
service and updates General's model entry. It used to name a piece of the
chat page that was removed some time ago. Installing this release restarts
General's service and the monitoring dashboards briefly; the chat page and the
chat model are untouched.
