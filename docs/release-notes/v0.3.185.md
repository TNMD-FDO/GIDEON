# GIDEON v0.3.185

Template: 3

## What is new

Nothing changes in either chat. This release tidies the box's GPU board and
prepares the ground for a smaller trial box.

On the GPU board, the first chart is now titled "GPU utilization". The GPU
memory chart now counts in gigabytes throughout, instead of mixing megabytes
and gigabytes on one axis, and a table beside it shows each line's current
value, so the top line can be read at any screen size. The memory in use is
labelled "used" beside "free".

Behind the scenes, the case-law collection can now be cut to one chosen court,
for a trial box that carries a single court. A smaller pair of models was also
tried on a card capped to that trial box's size: the smaller search model fit,
and the trial answering model did not start, so the choice of that model stays
open. Neither change reaches the box you use.
