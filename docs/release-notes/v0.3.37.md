# GIDEON v0.3.37

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON's second search store, the
one that finds documents by their exact words and citations, now runs on the
server, empty until a later release fills it. It is reachable only from inside
GIDEON, behind its own password, and GIDEON's monitoring emails the
administrators if it stops answering. Installing this upgrade briefly restarts
the chat's connection to GIDEON and the monitoring dashboards.
