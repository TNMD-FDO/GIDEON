# GIDEON v0.3.3

Template: 3

## What is new

Nothing you can see in the chat has changed. A backup copied off the box within a
few minutes of being taken could not be restored: the restore stopped with the
database restarting over and over. Every backup now records one small marker
transaction at its end, so a restore from any backup, however soon it was copied,
brings the database back up. Backups taken before this release become safe to
restore after the next night's backup.
