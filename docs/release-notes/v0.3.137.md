# GIDEON v0.3.137

## What is new

The runbooks now give each command the way you type it on an installed box,
`gideon …`, the same spelling the start-here card and the alert email already
use, so a page email and the runbook it points to no longer show two spellings
of one command. Upgrade day reads `gideon upgrade` followed by the tag, and
`gideon upgrade --rollback` throughout. The steps before the install runbook's
provision step, and the few lines that run from a different copy of the code or
on a box not yet provisioned, keep the longer `sudo python3 -m gideon …` form,
since the short command does not exist there yet. No step's wording or order
changed.
