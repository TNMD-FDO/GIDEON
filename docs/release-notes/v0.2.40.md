## What is new

Nothing you can see has changed. This release only changes the project's own
release tooling. When a release has to be prepared a second time, the tooling
now recognises its own earlier version number and keeps it. It no longer treats
that number as taken and skips to the next one. The chat, its answers, and its
coverage do not change.
