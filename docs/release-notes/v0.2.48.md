# GIDEON v0.2.48

Template: 3

## What is new

Nothing you can see in the chat has changed. For the office's CSA, the box now
has one `gideon` command that works from any folder: typed alone, it prints
where to start, grouped by situation — an alert arrived, a decision is
waiting, a certificate changed, backups, upgrade day — with `gideon status`
first. It runs every command as the administrator, and `sudo` asks for the
password at most once a sitting. Commands that do not work yet now say which
later release brings them.
