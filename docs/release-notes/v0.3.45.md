# GIDEON v0.3.45

Template: 3

## What is new

Nothing you can see in the chat has changed. On the server, the box status
the CSA reads now prints every fix in the same form the CSA typed: someone
who runs the short `gideon status` command reads fixes that start with
`gideon`, and each fix works from wherever it is typed. When that short
command cannot start at all, it now says what to repair and ends with the
status's "could not check" code rather than its "a page is firing" code, so
the two can no longer be confused.
