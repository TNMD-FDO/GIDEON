# GIDEON v0.3.172

Template: 3

## What is new

Nothing user-visible. The installation check now accepts a server with more
graphics cards than its selected configuration needs, running that
configuration on the first cards and naming the others as unused; a server with
fewer cards is still refused. The release also records how a smaller one-card
configuration behaves on this server, ahead of offering it.

## What was bumped

No pin moved since v0.3.171.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
