# GIDEON v0.3.84

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON's server setup keeps a file
that tells containers how to reach the server's graphics cards. It could go out of
date after a card was changed, the graphics driver was upgraded, or the server
restarted. Each time GIDEON is installed or upgraded, its setup now checks that file
against the cards and rewrites it only when it has gone out of date. A person no
longer has to rewrite it by hand after a driver upgrade. Upgrading to this release
restarts the monitoring dashboards for about a minute.
