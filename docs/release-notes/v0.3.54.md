# GIDEON v0.3.54

Template: 3

## What is new

Nothing you can see in the chat has changed. On the server, GIDEON's background
worker can now reach only the legal sources the release lists for collecting
case law and statutes, over HTTPS, and nothing else on the internet. The box
enforces this itself, so it no longer depends on the office's firewall. If the
office uses a proxy, that traffic still goes through it.

No pin moved since v0.3.53.
