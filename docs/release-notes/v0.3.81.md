# GIDEON v0.3.81

Template: 3

## What is new

Nothing you can see in the chat has changed. When GIDEON sets up its server, a few
steps restart every application running on it, or need the server restarted. GIDEON
now stops before such a step whenever another application's containers are running,
names them, and goes ahead only once the operator confirms the maintenance window was
announced. Upgrading to this release restarts the monitoring dashboards for about a
minute.

## What was bumped

No pin moved since v0.3.80.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
