## What is new

The two model servers on the server, the one that writes General's answers and
the one that prepares text for search, now require their own key on every
request except the two health checks the monitoring reads. Before, a few of
their lesser-used addresses answered any program on the server's internal
network without the key. Nothing reachable from an office computer changes,
and nothing changes in how anyone uses General.
