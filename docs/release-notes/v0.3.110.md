# GIDEON v0.3.110

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, the part of the
box that checks each answer as it streams, and refuses one that computes a
deadline or a sentence figure, was reorganised so that each piece of it lives in
one place. The answers, the refusals, and the record a refusal leaves are
exactly what they were. Installing this release briefly restarts the chat's
connection service and the monitoring dashboards; the chat model is untouched.

## What was bumped

No pin moved since v0.3.109.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
