# GIDEON v0.3.107

Template: 3

## What is new

Nothing you can see in the chat has changed. For the CSA at the box: when
`gideon host provision`, `gideon preflight`, `gideon users reconcile`,
`gideon tls reload`, `gideon registry mirror`, `gideon alerts test`, or
`gideon worker verify` refuses, the fix it prints now names the command the
way you typed it — `gideon …` when you ran the installed `gideon` command,
the long `python3 -m gideon …` form otherwise — so the fix can be copied and
run where you stand. The same holds for two fixes that `gideon backup run` and
`gideon restore` print about the backup store and the box's backup identity.
Only the command inside each fix changed; its wording did not. Installing this
release restarts the monitoring dashboards briefly; the chat model is
untouched.
