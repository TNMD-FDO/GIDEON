# GIDEON v0.2.14

Template: 2

## What is new

Nothing you can see in the chat has changed. This release is work on the test set GIDEON is measured against: it teaches the measuring tools to read the rest of the ways a citation is written — regulations, the appendix titles of the U.S. Code, the habeas rules, the Supreme Court's rules, and docket numbers — and it adds, to each question already in the set, the other spellings a person might reasonably type. The set is now fixed, so from here it grows only by addition and every later release is measured against the same questions.
