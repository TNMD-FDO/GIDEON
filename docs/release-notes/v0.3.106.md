# GIDEON v0.3.106

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, every court
opinion the box has read now records which printed reporter page each stretch
of its text sits on, taken from the page marks in the opinion itself and never
guessed. This is what later lets an answer cite an opinion to its page. Where
an opinion carries no page marks, or a passage comes before the first one, the
box records that the passage has no page rather than inventing one. The
opinions already on the box gained their pages on the next ingest run, with
nothing downloaded again. Installing this release restarts the monitoring
dashboards briefly; the chat model is untouched.
