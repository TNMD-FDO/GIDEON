# GIDEON v0.3.176

Template: 3

## What is new

Nothing user-visible in the chat. Behind the scenes, the box's monitoring
boards read more plainly: the Overview's top row keeps its cards whole, the
Backup and Evaluation tables give durations and sizes in human units, and the
Corpus board's tables fit their cards and its charts name each search-index
generation by a short name with a key that shows every line. The case-law
pipeline reads an opinion's page breaks more carefully and records more of
its sections; a production search-index build now refuses to start
until the test stack's checks have passed; the evaluation checks gain new
practice questions and state how many cases each pass rests on; restoring a
backup now brings back the case-law registry its backup carries; and a check
of the box's outbound network tries again before it reports a fault.
