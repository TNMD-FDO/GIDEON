# GIDEON v0.3.160

Template: 3

## What is new

Nothing user-visible. The build that prepares the case-law search index now
does its second half: it turns each passage of the collected opinions into the
numeric form the Legal chat will search by meaning, keeps a record of which
passages are already done so a stopped build picks up where it left off, and
reports its speed and expected finish in its first hour. Searching the index
arrives with the Legal chat at go-live.

## What was bumped

No pin moved since v0.3.159.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
