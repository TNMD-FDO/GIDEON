# GIDEON v0.2.57

Template: 3

## What is new

Nothing you can see in the chat has changed. This release changes how GIDEON
checks itself. When the safety test finds that General refused an ordinary
question it should have answered, it no longer relies only on the shape of the
reply. A second model now reads each refusal and says whether the answer was
really held back. Both results are reported side by side. Neither one stops a
release.

No pin moved since v0.2.56.
