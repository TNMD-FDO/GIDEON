## What is new

Nothing you can see in the chat has changed. The script that prepares each
release now holds the release's version number from the moment it accepts it.
Before this, two releases prepared at the same time could both pick the same
number. The later one then had to be renumbered and checked again. This is an
internal tooling change, and GIDEON itself behaves exactly as before.
