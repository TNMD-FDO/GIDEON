# GIDEON v0.3.147

Template: 3

## What is new

Nothing user-visible. The monitoring dashboards have one emergency administrator
account whose password the office keeps in its password manager. If that
password is ever changed inside the dashboards and not written down, the
administrator can now reset it with one command, without knowing the old one;
the command saves the new password where GIDEON keeps it, checks that it signs
in, and reminds the administrator to copy it into the password manager. Nothing
restarts, and nothing changes in how anyone uses General.
