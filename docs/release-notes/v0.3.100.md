# GIDEON v0.3.100

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, every court
opinion GIDEON has taken in is now divided into labelled parts — the court's
opinion, a concurrence, a dissent, the syllabus, head matter, footnotes — so
that a later release can tell a dissent from the holding when it answers. A
part GIDEON cannot label with confidence is marked unknown rather than guessed.
`gideon corpus install` now prints each court's share of each kind of part, and
refuses to finish if an opinion it took in has no parts. Installing this release
restarts the monitoring dashboards and three background services briefly; the chat model is untouched.
