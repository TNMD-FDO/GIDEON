# GIDEON v0.2.97

Template: 3

## What is new

Nothing you can see in the chat has changed. This release corrects how GIDEON's
own test runs read an answer the arithmetic guardrail replaced: the part of the
answer that stood before the refusal is now checked exactly as it was sent,
line breaks included. Before, the test runs could miss a figure that should
have been caught or report one that was never sent. The guardrail itself, and
what it shows a person in the chat, are unchanged.

## What was bumped

No pin moved since v0.2.96.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
