# GIDEON v0.3.90

Template: 3

## What is new

Nothing you can see in the chat has changed. When the server raises an alert, the
email now links to the instructions for that alert on the public project page, at
the exact version the server runs. The box status and the start screen you see when
you type `gideon` now give the full path to those instructions on the server. Before
this release all three named a path that only made sense to a developer. Upgrading
to this release restarts the monitoring dashboards and the chat service for about a
minute.

## What was bumped

No pin moved since v0.3.88.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
