# GIDEON v0.3.77

Template: 3

## What is new

Nothing you can see in the chat has changed. When GIDEON is installed or upgraded,
its check of the server now also looks at how much memory the server has free, now
and at its lowest over the past two weeks. If either is below a fifth of the server's
memory, the check prints a warning saying so, with the figures. It never stops the
install or the upgrade. Upgrading to this release restarts the monitoring dashboards
for about a minute.
