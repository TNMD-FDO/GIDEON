# GIDEON v0.3.43

Template: 3

## What is new

Nothing you can see in the chat has changed. The check GIDEON runs on its
models after an install, an upgrade, or a driver change now also checks the
second model, the one that turns text into the vectors document search will
use: that it answers in the right shape, and how fast it works through a batch
of text. If that model is stopped or failing, the check says so and names the
fix. This release restarts nothing.

## What was bumped

No pin moved since v0.3.42.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
