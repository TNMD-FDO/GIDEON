## What is new

Nothing you can see in the chat has changed. On the GPU dashboard, the cards for
GPU use, memory, temperature, and power now show each graphics card once in their
legends, however far back you look. Before, a routine restart of the part that
reads the cards could make each one appear twice for hours afterwards.
