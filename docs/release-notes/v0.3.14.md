# GIDEON v0.3.14

## What is new

The monitoring dashboard's home page now shows only what can raise an alert,
each card turning red at the same point its alert fires. Each service is one
named tile, green when it is up and red when it is down. Free disk space is
three bars, one for each disk an alert watches. A new card shows how many days
remain before the box's certificate expires. The host load and memory charts
are in a collapsed "Host detail" section at the foot of the page. The two GPU
charts are on the GPU dashboard only. The age of the last test-account
guardrail trip is on the Eval dashboard.
