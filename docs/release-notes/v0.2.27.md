## What is new

Nothing you can see has changed yet. GIDEON adds one short line — "General does not verify citations." — under any answer that looks like it cites a statute, a case, a rule, or a database record. That line is a reminder to check the citation yourself; it never means GIDEON found something wrong.

Until now that reminder was added by a piece of the chat page. This release teaches GIDEON's own General service to add it as well, so the reminder will keep appearing once a later release moves the chat page onto that service. Both copies are held identical by a test, and only the chat page's copy is in use today, so you will not see the line twice.
