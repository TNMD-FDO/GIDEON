# GIDEON v0.3.179

Template: 3

## What is new

Nothing user-visible in the chat. Behind the scenes, a newly built search
index can now be switched into service in one step, after its quality checks
pass, and a single answer always reads from one index version even while a
switch happens. The case-law install keeps its per-court counts in its own
records, so they can be shown again for a collection installed earlier. The
quality board now shows how often the safety rules caught a problem
themselves, apart from the times the model declined on its own.

## What was bumped

No pin moved since v0.3.178.
