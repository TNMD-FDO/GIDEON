# GIDEON v0.3.80

Template: 3

## What is new

Nothing you can see in the chat has changed. When GIDEON is installed on a server
where the office, or another application, already keeps a data drive at `/data`,
the install now uses that drive when it is large enough for the server's hardware
profile and formatted as XFS or ext4: GIDEON adds its own folders there and leaves
the drive itself, and how it is mounted, as it found them. A drive too small or of
another format stops the install with a message naming what was found and what is
needed. On this office's server, where GIDEON built `/data` itself, nothing changes.
