# GIDEON v0.3.2

Template: 3

## What is new

Nothing you can see in the chat has changed. The box's administrators now have
a one-page card, `docs/runbooks/start-here.md`, that lists what to do and when:
every day, when an email arrives, once a week, once a month, on upgrade day, and
when something looks wrong. Each item gives the command to run and the runbook
section with the steps. Running `gideon` with no arguments now names the card,
and so does the README.
