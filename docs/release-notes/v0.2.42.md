# GIDEON v0.2.42

Template: 3

## What is new

Nothing you can see in the chat has changed. The release gains a runbook for
its own files, `docs/runbooks/release-files.md`: what each lock and committed
file pins, who edits it, and what to do when a command refuses on one of them.
The install runbook gains a procedure for moving a populated image store to the
Docker volume, `docs/runbooks/install-upgrade.md` §7. The refusals that used to
name an internal design document now name the runbook section that answers
them. The public repository no longer carries the internal design documents,
the architecture map and the decision records among them. The chat, its
answers, and its coverage do not change.
