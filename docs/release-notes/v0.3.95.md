## What is new

Nothing you can see in the chat has changed. This release improves the
developers' own tooling: the check they run before changing the server now
notices when AI models are being downloaded, and when an update to the server
has started but not yet finished. Upgrading to this release restarts the
monitoring dashboards for about a minute.
