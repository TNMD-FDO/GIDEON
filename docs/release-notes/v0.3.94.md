# GIDEON v0.3.94

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON can now read the court
opinions it has downloaded and turn each one into a document it keeps: the text
of the opinion, cleaned the same way every time, stored beside the original as
the court's site published it, with the court, the date decided, and whether the
opinion is published or unpublished. An opinion that cannot be read is kept as a
named failure rather than silently dropped, so every downloaded opinion is
accounted for. Installing the same case-law set again changes nothing. This is
the first step toward the Legal chat; the search over these documents comes in
later releases. Upgrading to this release restarts the chat service, the
background worker, and the monitoring dashboards for about a minute.
