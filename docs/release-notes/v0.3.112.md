# GIDEON v0.3.112

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, every citation
to a case in the court opinions the box has read is now checked for explicit
language about how the citing court treated that case — overruled, abrogated,
superseded, reversed, vacated, or disapproved — in the sentence around the
cite, leaving out phrases such as "declined to overrule". Each finding records
whether it came from a court whose ruling binds the cited case, and when it
does not count — a dissent, for instance — it records why. None of this is
shown yet: the warnings it will feed stay switched off until their accuracy
has been measured. The opinions already on the box gained their findings on
the next ingest run, with nothing downloaded again. Installing this release
restarts the monitoring dashboards briefly; the chat model is untouched.
