# GIDEON v0.3.173

Template: 3

## What is new

Nothing user-visible. Installing a new corpus now also builds the search
indexes whose documents changed and prints the step that switches over to
them, which a person still runs. Before an index build, the server now checks
that the data volume has room to hold a new index beside the current ones; the
"Data volume low" alert and the installation check warn when it does not, and
the check never refuses because of it. The test system can now build a small
evaluation index of its own, independent of the office's.
