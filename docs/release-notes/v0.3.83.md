# GIDEON v0.3.83

Template: 3

## What is new

Nothing you can see in the chat has changed. When the people who run GIDEON install
its collection of court decisions, GIDEON now sorts the downloaded records by court,
keeping only the courts the Legal chat will cover, so the next steps of the build can
work from them. This preparation runs on the server in the background and takes a few
hours. Upgrading to this release restarts some of GIDEON's background services and the
monitoring dashboards for about a minute.

## What was bumped

No pin moved since v0.3.82.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.
