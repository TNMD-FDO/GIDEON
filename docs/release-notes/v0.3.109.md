## What is new

Nothing you can see in the chat has changed. This release shortens the
developers' own release steps: a release that touches none of the services
no longer waits for its own trial run before publishing, since the same trial
runs automatically afterwards, and a release whose only catch-up is
bookkeeping re-checks just that bookkeeping. Nothing on the server is
restarted.
