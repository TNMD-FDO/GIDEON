# GIDEON v0.3.46

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind it, GIDEON can now
recognise a court case citation, such as a reporter volume and page, with
eyecite, a widely used open-source citation tool. It is
measured on the server against invented examples and found every one
without a false match. The chat will start to use it in a later release.
