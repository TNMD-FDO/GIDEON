# GIDEON v0.3.66

Template: 3

## What is new

Nothing you can see in the chat has changed. Setting up GIDEON on a server where
another app already installed Docker no longer adds a second copy of Docker's
software source. Two copies would have stopped every later system update on the
server. When two are already there, the setup stops before changing anything,
names both files, and an administrator removes one. A Docker that is already
installed is accepted however it was installed. No service an office runs is
restarted.
