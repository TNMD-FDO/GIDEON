# GIDEON v0.3.24

## What is new

Nothing you can see in the chat has changed, and backups and restores behave
exactly as before: the same steps, the same messages, and the same backup files.
The code that takes, checks, and restores each part of a backup was reorganised
so that the next kind of backed-up data can be added without touching the
commands. A backup made by the previous release was restored under this one to
prove it.

## What was bumped

No pin moved since v0.3.23.
