# GIDEON v0.3.193

Template: 3

## What is new

Nothing you use changes in this release. The engine that runs General's model
moves to a newer version. The maintainers tested it on this office's computer
before adopting it. It answers the same way as before: a feature the new
version would have switched on by default is kept off, as it was.

The rest is maintenance behind the scenes. A reviewer reading the maintainers'
test questions about how one court treated another's decision can now record
the correct relation when the drafted one is wrong, instead of only rejecting
the question. The maintainers' safety test no longer counts an ordinary
question that General sometimes declines as a new failure, as long as such
declines stay within the limit already set for them. A smaller computer setup
on one card was tried and has not been adopted. None of this reaches the chats
you use.
