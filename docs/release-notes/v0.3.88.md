# GIDEON v0.3.88

Template: 3

## What is new

Nothing you can see in the chat has changed. Three of the server's checks sign in to
the monitoring dashboards as their emergency administrator: the box status, the alert
test, and the dashboard check. They now read that administrator's password in one
place. When the password file is missing, unreadable, or empty, all three stop before
sending anything and print the same instruction: rewrite the file from the office
password manager, then try again. Before this release an empty file showed up later as
a confusing sign-in failure. Upgrading to this release restarts the monitoring
dashboards for about a minute.
