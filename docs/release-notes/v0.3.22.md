# GIDEON v0.3.22

## What is new

Nothing you can see in the chat has changed. Inside the box, each service GIDEON
runs is now described once, in one place, and the stack's configuration is built
from those descriptions; the configuration the box runs is the same, byte for
byte. This prepares the services the next releases add.

## What was bumped

No pin moved since v0.3.21.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

tag's note announces the first window.
