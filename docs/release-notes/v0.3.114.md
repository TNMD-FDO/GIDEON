# GIDEON v0.3.114

Template: 3

## What is new

Nothing you can see in the chat has changed. For the person who looks after
the server, GIDEON can now be taken off a box by one command,
`gideon uninstall`. It removes only what GIDEON put there: its services, its
scheduled jobs, its firewall rules, its networks, and the `gideon` command
itself. It changes nothing another application on the same server relies on,
such as the firewall's default policy, the SSH settings, Docker's settings, or
the data disk. A plain run keeps GIDEON's configuration and data, so a later
install finds them again; `gideon uninstall --purge` removes those too, but
never the data disk itself. Before it stops anything, the command lists any
other application's containers that use GIDEON's chat model, and it is
announced in advance like an upgrade, since every GIDEON service stops. The
steps are in the install and upgrade runbook's new section 11. Installing this
release restarts the monitoring dashboards briefly; the chat is untouched.
