## What is new

Nothing you can see in the chat has changed. The install instructions, in the
README and in the install runbook, now begin with a "Before you begin" list: the
Ubuntu release and the packages the machine needs, the login to use, the hardware
the reference build expects, the size of the first model download, and the office
services to have ready. The first step now explains which login and which release
tag to fill in, with an example, and says that no GitHub account is needed to
install or upgrade. Both documents now give the same seven steps with
the same commands.
