# GIDEON v0.3.142

Template: 3

## What is new

Nothing user-visible. Before the Legal chat's library is built in full, the
team now checks how well GIDEON divides each court opinion into its parts — the
court's opinion, a dissent, a concurrence, the footnotes — against three
hundred opinions that a person reads and marks by hand. A dissent read as the
court's own opinion fails the check. The opinions are chosen and the tools for
marking them are in place; the person's reading of the three hundred comes
next. Nothing changes in how anyone uses General.
