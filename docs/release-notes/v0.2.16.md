# GIDEON v0.2.16

## What is new

Nothing you can see in the chat has changed. This release builds the tools for a piece of preparation work that happens away from the system: a set of real questions, each with a handful of passages from the case law, is given to attorneys who mark how well each passage answers its question. Those marks become the yardstick GIDEON's search is measured against — without them there is no way to tell whether a change to how it finds things made the answers better or worse.

What was built is the paperwork around that job. GIDEON can now produce a folder for each attorney holding a one-page instruction and one self-contained page per question, which opens in an ordinary browser with no access to GIDEON and no internet connection. Each page shows the question and its passages in a fixed order, with no hint of which the system thought was best, so a reader's judgement is their own. When the marks come back, GIDEON checks them — every passage marked, every mark on the scale, and the pages still the ones that were sent out — and records them, keeping only the marks and never the text. It also reports how closely two attorneys agreed on the tenth of the questions that are deliberately given to both.

No attorney has been asked for their time yet. The tools were built and tested against invented material first, so that any awkwardness in them is found before anyone spends hours on them.
