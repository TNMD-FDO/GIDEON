# GIDEON v0.3.154

Template: 3

## What is new

Nothing user-visible. The engine check that every install and update runs
before it finishes no longer fails an update when the model declines the
deadline test case on one try: a try that tests nothing is sent again, up to
three times, while a try that shows a fault still fails at once. When every try
declines, the update's message says to run the check again by hand, and it no
longer tells the office to roll back a sound update.
