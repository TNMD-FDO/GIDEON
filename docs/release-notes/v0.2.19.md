## What is new

Nothing you can see in the chat has changed. This release is for the people who check GIDEON's answers before a change reaches you. Until now those checks could only be run the way a person uses GIDEON — by signing in and asking in the chat window. They can now also be run against the part of GIDEON that sits behind the chat window, directly. That matters because it lets the checks tell the difference between a problem in GIDEON itself and a problem in the window you read it through, and because the same checks will keep working when the window changes.
