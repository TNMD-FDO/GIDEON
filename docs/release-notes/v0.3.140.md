## What is new

The email the server sends when something needs a person's attention now puts
each problem's link to the instructions on a line of its own, below the line
describing the problem. Before, the link sat at the end of that line, and a
mail program could break it in two, leaving it hard to open. Nothing changes in
how anyone uses General.
