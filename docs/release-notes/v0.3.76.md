# GIDEON v0.3.76

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON's firewall rules for the box's
web address now sit in a list of their own. Another application on the same server
can therefore add its own firewall rules without GIDEON erasing them the next time
it checks the box. Who can reach GIDEON is unchanged: only the office's own networks.
Upgrading to this release restarts the monitoring dashboards for about a minute.

## What was bumped

No pin moved since v0.3.75.
