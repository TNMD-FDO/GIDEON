# GIDEON v0.3.182

Template: 3

## What is new

Nothing user-visible in the chat. Behind the scenes, restoring from a backup
now checks the search indexes against the record of what was built: an index
that came back whole is switched back on, and one that came back short is
marked for rebuilding instead of being served incomplete. Building or switching
to a new search index now checks the memory every index on the box needs
together, not only the new one, so two indexes side by side cannot overrun it.
The backup guide now states, for each kind of failure, how much recent work a
recovery can lose and how long it takes to answer again. Two checks used only
in testing and maintenance now read their inputs correctly.
