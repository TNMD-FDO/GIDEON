## What is new

Nothing you can see in the chat has changed. The operator's guide to the release
files now lists every setting that depends on the box's hardware — its graphics
cards, its memory, and its disk — where each one lives, and how each would move on
a smaller machine. It is the first page to read when an office asks whether GIDEON
will run on its hardware. GIDEON still runs on one tested machine shape; no new one
is offered.

No pin moved since v0.3.122.
