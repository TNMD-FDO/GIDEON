# GIDEON v0.3.73

Template: 3

## What is new

Nothing you can see in the chat has changed. The installer now accepts a
graphics-card driver and its container toolkit that are already installed on
the server, however they were installed, as long as they are new enough and
use the open driver the cards require. It installs its own only when none is
there, and it never replaces one another application on the server relies on.
A driver that was upgraded but is waiting for a restart is reported, and the
restart is left to an announced maintenance window. On this office's server
the driver is already the one the installer would have chosen, so nothing
changes. Upgrading to this release restarts nothing you use.

## What was bumped

No pin moved since v0.3.72.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
