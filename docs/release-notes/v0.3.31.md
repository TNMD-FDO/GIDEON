# GIDEON v0.3.31

Template: 3

## What is new

Nothing you can see in the chat has changed. This release tidies how the server
lists the passwords and keys its services use, so that each one is listed
because a service needs it and for no other reason. Installing this upgrade
restarts every service on the server once, the chat engine included; nothing
else about the server changes.

## What was bumped

No pin moved since v0.3.30.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
