# GIDEON v0.3.75

Template: 3

## What is new

Nothing you can see in the chat has changed. The command that installs the legal
corpus on a box now does its first part: it brings onto the box every file of the
pinned case-law collection the box does not already hold, checks every file against
its recorded fingerprint, and refuses, naming the file and what to do, when one is
damaged or missing. Building the searchable index from those files arrives in a
later release. Upgrading to this release restarts the monitoring dashboards for
about a minute.

## What was bumped

No pin moved since v0.3.74.
