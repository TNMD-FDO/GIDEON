# GIDEON v0.3.177

Template: 3

## What is new

Nothing user-visible in the chat. Behind the scenes, the evaluation checks
gain practice questions the system should decline — questions the case law
cannot answer, questions that lead toward a wrong court or an invented case,
and questions built on a false premise — and each set of practice questions
now keeps a held-out part that tuning never reads. A candidate search index
is now checked by one combined evaluation pass before it can be promoted, a
trial index groups its near-duplicate documents the way a full one does, and
the grading packets can now be drawn from a full search index rather than a
sample of it.
