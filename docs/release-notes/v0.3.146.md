# GIDEON v0.3.146

Template: 3

## What is new

Nothing user-visible. The backup and restore runbook's total-loss procedure now
says what to expect on the server that builds GIDEON's own images: the fresh
install stops at its registry step until the restore brings those images back,
and the registry's copy is put back by hand before the restore runs. Nothing
changes in how anyone uses General.
