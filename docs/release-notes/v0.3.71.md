# GIDEON v0.3.71

Template: 3

## What is new

Nothing you can see in the chat has changed. The nightly backup now keeps a
file that someone attaches in the chat while the backup is running: it copies
the chat's file folder a second time after the database is saved. Restoring
the system to a chosen moment now brings back the files attached up to that
moment instead of removing them. Nobody can attach files in the chat yet, so
this protects attachments from go-live on. Upgrading to this release restarts
nothing you use.

## What was bumped

No pin moved since v0.3.70.
