Nothing you can see in the chat has changed. GIDEON's release checks now
install it on a test machine beside a made-up second application, once with
that application there first and once with GIDEON there first, and confirm
that installing, upgrading, and removing GIDEON leaves the other application
running and its data in place. The checks found one fault, now fixed:
removing GIDEON's kept settings after an earlier removal stopped partway.
