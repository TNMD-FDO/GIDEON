# GIDEON v0.3.60

Template: 3

## What is new

Nothing you can see in the chat has changed. On the server, GIDEON can now download
a public court-data file into its own storage and check it as it arrives. If a
download is cut short, it picks up where it stopped. If the file changed upstream
in the meantime, the download is refused and never patched together. The first
download, the newest public case-law dump, is in place for the work that builds
the Legal chat's library.

## What was bumped

No pin moved since v0.3.58.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.
