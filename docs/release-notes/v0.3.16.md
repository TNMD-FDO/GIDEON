# GIDEON v0.3.16

Template: 3

## What is new

The Backup dashboard opens on the last 35 days, so a month of backups fills each
chart instead of sitting at its right edge. Its restore-drill table lists the five
newest drills, and its table of recent runs shows all ten rows inside the card. In
that table every row now says how it ended — "completed" for a backup, a push, or a
restore, and "pass" or "failed" for a drill — and the hard-link column reads the
share of files the backup reused, as a percentage, where it used to show raw text.
On the Eval dashboard the guardrail counts table now spans the full width, and every
column heading on its tables reads whole.
