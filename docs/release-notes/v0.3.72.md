# GIDEON v0.3.72

Template: 3

## What is new

Nothing you can see in the chat has changed. The installer's pre-flight check
now compares the office's home courts with the list of courts the release's
case-law collection covers. A home court the collection should cover but does
not stops the install; a home district or state whose courts have not been
added yet gives a warning that says how to add them. On this office's system
the check warns that the Middle District of Tennessee and the Tennessee state
courts are not in the collection yet. Upgrading to this release restarts
nothing you use.
