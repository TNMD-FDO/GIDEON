# GIDEON v0.3.108

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, every court
opinion the box has read now records each citation it makes — a full cite, a
short form, an "Id.", a "supra", or a reference back to a named case — at the
exact place in the opinion where it appears. A cite to a case the box holds is
linked to that case; a cite the box cannot match keeps its own wording and no
link, so nothing is dropped and nothing is guessed. This is what later lets an
answer show what an opinion relies on and which opinions rely on it. The
opinions already on the box gained their citations on the next ingest run, with
nothing downloaded again. Installing this release restarts the monitoring
dashboards briefly; the chat model is untouched.
