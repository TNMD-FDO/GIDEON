# GIDEON v0.3.7

Template: 3

## What is new

While General thinks before it answers, a line above the answer now shows that
it is still working and for how long: "Thinking…", then "Thinking… 55s" or
"Thinking… 1m 5s" as the seconds go by, and "Thought for 3m 57s" once the answer
begins. The line only counts time; it never shows what General is thinking. It
stays with the chat, so it is still there when you reopen it. If you press Stop
while General is thinking, the line keeps its last reading.
