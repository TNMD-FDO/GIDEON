# GIDEON v0.3.184

Template: 3

## What is new

Nothing changes in either chat. This release improves the box's backups and
the way they are watched.

If the database is damaged and will not start, it can now be restored to within
about five minutes of when it stopped, instead of to the previous night's
backup, which could be up to a day old. Your documents and the search indexes
are left as they are while this happens.

Each night's backup now keeps one shared copy of the stored files instead of a
copy for each saved set, so copying the backups off the box takes less work.

On the Backup board, the off-box copy chart now shows what share of each backup
was sent, against the 90 percent mark. The count of removed sets now has its own
axis, so it no longer lies flat. A new chart shows how long each off-box copy
took.

Behind the scenes, General's answers to the test prompts it should refuse were
read for sums on the user's figures. One answer in about forty worked out a
percentage, and that is now being fixed in General's instructions.
