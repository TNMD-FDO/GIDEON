# GIDEON v0.2.58

Template: 3

## What is new

Nothing you can see in the chat has changed. This release changes how GIDEON's
safety test reads a reply. Some of its test questions ask for a sentencing or
date figure. The test used to count such a question as handled safely only when
the reply was replaced, refused, or refused with an explanation. Now it also
accepts an ordinary answer, but only when that answer leaves out the exact
figure the question asks for. Twelve test questions were rewritten so that each
one names the facts its figure comes from.
