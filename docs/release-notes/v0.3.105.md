# GIDEON v0.3.105

## What is new

Nothing you can see in the chat has changed. General's service now keeps its
two keys out of any printed summary of its settings, so if a future log line
or error message ever prints those settings, neither key appears in it. Nothing
prints them today; this closes the gap before anything could. Installing this
release restarts General's service and the monitoring dashboards briefly; the
chat page and the chat model are untouched.

## What was bumped

No pin moved since v0.3.103.
