# GIDEON v0.3.128

Template: 3

## What is new

Nothing you see in the chat has changed. The check that runs before every
install and upgrade now looks at the server's internal container networks, and
stops, naming the network and the application that made it, when one of them
would cut the server off from an office system it depends on, such as the mail
relay or the directory server. Before, that situation showed only as the mail
or directory check failing with a routing error that pointed nowhere.
