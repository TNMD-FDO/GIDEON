## What is new

Nothing you can see in the chat has changed. When a later upgrade adds a
password or key that only some services use — or when the alert e-mail's user
is set or cleared — only the services that use it restart, where before every
service on the server restarted. The preview an administrator reads before an
upgrade now says, under its list of services to restart, why each one is on
it. Installing this upgrade restarts nothing for this change.
