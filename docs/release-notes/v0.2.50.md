# GIDEON v0.2.50

Template: 3

## What is new

Nothing you can see in the chat has changed. The thumbs-up and thumbs-down
under each answer stay on by design now, so a user can tell the office whether
an answer helped, or that a check stopped an answer it should not have. GIDEON
reads which way the thumb went and which answer it was on, and nothing a user
types in the "tell us more" box. For the office's CSA, `gideon proposals`
gains a `feedback` section that counts the last thirty days' thumbs by model.
