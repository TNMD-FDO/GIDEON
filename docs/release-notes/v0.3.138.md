# GIDEON v0.3.138

Template: 3

## What is new

The office's search store now reports its own health to the monitoring board:
how much memory it uses, how busy it is indexing and searching, and whether it
is answering. GIDEON now builds the store's image on the server, adding a small
monitoring add-on to the published image and checking that file against a
recorded fingerprint before installing it. The monitoring uses a password of its
own that can read these figures and nothing else; it cannot see any document in
the store. The Overview board shows the new figures' tile, and the "Target down"
alert email fires when they stop arriving. Nothing changes in how anyone uses
General. The store's version is unchanged at 3.8.0: the bumped line below marks
its image becoming one GIDEON builds, where before it was used as published.
