## What is new

Nothing you can see in the chat has changed. Every change the development team
publishes is now checked at once against the office's own model on a separate test
copy of GIDEON: a short set of questions checks that the safeguards still refuse
what they must, and that GIDEON still answers ordinary questions the way it did.
The check sends twelve questions to the shared server, at any hour, and never
touches your chats.
