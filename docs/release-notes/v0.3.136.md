# GIDEON v0.3.136

Template: 3

## What is new

The microphone and the voice-call buttons are gone from the chat: speech input
was never a chosen feature, and pressing the microphone would have made the
server download a speech model from the internet. Reading an answer aloud still
works, using your browser's own voice. On the server, the chat no longer loads
or checks for an unused language model when it starts.

## What was bumped

No pin moved since v0.3.135.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
