# GIDEON v0.3.65

Template: 3

## What is new

Nothing you can see in the chat has changed. Setting up or upgrading GIDEON no
longer upgrades Docker, the GPU driver, or the container toolkit on its own, so
it can no longer restart every app on the server without warning. When one of
them is older than GIDEON needs, the setup stops and names it, and an
administrator upgrades it in an announced maintenance window by the steps in the
install runbook. No service an office runs is restarted except the monitoring
dashboard.

## What was bumped

No pin moved since v0.3.64.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
