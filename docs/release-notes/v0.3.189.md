# GIDEON v0.3.189

Template: 3

## What is new

Nothing changes in either chat. This release is maintenance behind the scenes.

The monitoring overview's memory card now draws only GIDEON's own containers,
so their lines are readable instead of pressed to the bottom by the other
application's larger limits. A second card beside it shows each container's
memory as a share of its limit, from 0 to 100 percent. Installing or upgrading
now removes from the disk the old GIDEON images the release no longer uses,
leaving the current ones and any still running; the disk is shared with Gideon
Transcribe, whose images are never touched. On the maintaining office's build
box only, a new weekly job copies the court and model files the releases pin to
the office's source archive, sending only what the archive lacks, with two
alerts on the monitoring pages if it is late or fails. The backup drill's
temporary copy of the database and chat services is now built from the same
definitions as the live ones. None of this reaches the chats you use.
