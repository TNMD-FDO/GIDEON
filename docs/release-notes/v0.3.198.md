## What is new

The web search behind General now runs on a newer release of its search
service. It searches Bing and Wikipedia by default. Brave and Startpage stay
allowed for an office to turn on, but neither answered the server's searches
when the change was tested, so neither is on by default. The GPU page of the
monitoring dashboard now reads the counters by the names the newer GPU monitor
uses, and its utilization chart is drawn from 0 to 100 percent. The two GPU
alerts read the same names and behave as before.

This release also records a smaller one-card hardware profile beside the
reference server, described below. No office can install it yet. The rest of
the release changes how the project checks itself, and nothing in the chats
changes.

## Trial profile

The trial profile `1x32v-120d` is for a one-card office. It needs one NVIDIA
RTX PRO 4500 Blackwell card with 32 GB of memory, 120 GB of host memory, and
600 GB of data storage. It serves the generator `google/gemma-4-12B-it-qat-w4a16-ct`
and the embedder `Qwen/Qwen3-Embedding-0.6B`, whose vectors are their own space,
`qwen3-embedding-0-6b-1024-bf16`, never the reference's. The generator reads up
to 262,144 tokens and the embedder up to 4,096. The embedder shares the
generator's card, and no card memory is set aside for another application. Its
corpus line covers the Supreme Court alone.

The profile was evaluated on the project's own card, capped to the trial's
share of memory: `general-smoke` run `27b852e5-46d3-41b8-a01d-90871b49a680`,
`judge-triples` run `9bd08f25-3d99-4ad1-9bfe-7d47bf4937f8`, and `guardrails`
run `a8c9fae2-01fc-42eb-8333-dc2ca169ede4`, each passing. The named RTX PRO 4500
card has not yet been evaluated. This profile's quality claim rests on these
runs, never on the reference's. No office installs it before v1.0.0.
