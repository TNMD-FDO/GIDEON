# GIDEON v0.3.188

Template: 3

## What is new

Nothing changes in either chat. This release is maintenance behind the scenes.

The nightly copy of the box's backups to off-site storage now finishes inside
its time limit. It removes old off-site copies only after the new one is
checked and recorded, stops a slow removal before the limit rather than being
cut off part way, and reports what it removed on the backup monitoring page.
The library ingest's check for unreadable opinion text no longer mistakes a
court's plain list of case names or citations for scrambled text, so those
opinions are kept. Six unreadable cases in a frozen quality-check set are
replaced by readable ones. The monitoring pages' automated check now waits out
a monitoring server that has only just started instead of reporting a wrong
password. Building one of the box's own images now clears that build's leftover
files from the disk the box shares with Gideon Transcribe. None of this reaches
the chats you use.
