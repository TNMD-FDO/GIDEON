# GIDEON v0.3.21

Template: 3

## What is new

Nothing you can see in the chat has changed. The office services runbook, which
says what an office prepares outside the box before installing (the directory,
DNS, the backup target, certificates, and the mail relay), now reads as a checklist
for any office's own equipment: each section says what the install checks, then
the steps, with one office's setup kept as a labelled example. Placing the
directory and mail passwords and authorizing the backup key are each one command
to run. When a model download is refused because its source changed, the message
now says to report it as an issue on GIDEON's public repository.
