# GIDEON v0.3.197

Template: 3

## What is new

Nothing changes in the chats you use or on the server. This release finishes
the plain-paragraph rewrite of the install runbook, and no step, heading,
section number, or command in it has changed.

The runbook's second half, sections 5 to 12, now reads in the same voice as its
first half. The two records, the first server's install and upgrade and the
acceptance run, say what ran, when, and what it found. The six procedures an
office follows by hand in a maintenance window, such as setting the data
directory aside and copying it back, now give each step together with the
reason it comes where it does, so that a person who meets a state the text did
not foresee knows why a check precedes the step after it. The checks the
project runs on a proposed change also return their answer sooner, which
changes nothing an office installs.
