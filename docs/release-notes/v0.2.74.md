## What is new

Nothing you can see in the chat has changed. Behind it, the team's quality checks
and the commands that reconfigure the system now wait their turn: none of them starts
while an evaluation is running, so a measurement of GIDEON's speed is never skewed by
a second run beside it, and a reconfiguration never interrupts one.
