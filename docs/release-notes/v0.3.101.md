# GIDEON v0.3.101

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, an office can
now add courts to its case-law library without downloading anything again:
`gideon corpus cut` with `--base` and `--add-courts` starts from a library
version already shipped, adds the courts named, and writes a new version that
records where it came from. A court name GIDEON does not know is refused, with
the closest known name suggested. The steps, including how to look up a court's
name and how to use this to rebuild after a loss, are in the release-files
runbook, section 11. Installing this release restarts the monitoring dashboards
briefly; the chat model is untouched.
