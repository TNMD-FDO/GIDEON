# GIDEON v0.3.41

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON now runs a second model on
its second graphics card: the one that turns text into the vectors document
search will use. Nothing calls it yet; the search that uses it arrives later in
this slice. The monitoring Overview shows it as `embed` beside the answering
model's `engine`. Installing it restarts only the monitoring page and the
service a chat turn passes through, as an upgrade does; nobody is signed out.
