# GIDEON v0.3.67

Template: 3

## What is new

Nothing you can see in the chat has changed. Setting up or upgrading GIDEON no
longer rewrites the whole of Docker's settings file on the server. GIDEON keeps
the few settings it needs and leaves every other setting another app added in
place. When another app has changed one of GIDEON's settings to a value GIDEON
cannot work with, the setup stops before changing anything and names the
setting, the value it found, and the value GIDEON needs, so an administrator can
agree one value with the other app's operator. Docker restarts only when one of
GIDEON's own settings changes. No service an office runs is restarted.
