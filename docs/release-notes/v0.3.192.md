# GIDEON v0.3.192

Template: 3

## What is new

General is stricter about figures. When you ask how to work out a number for a
person or a matter, General still explains the rule or the method. It may do
so in general terms, or using your own figures as you gave them, written the
same way (a percentage as a decimal, a total as the numbers that make it up).
It no longer states any new figure worked out from yours, not even as one step
of the method or as an estimate. It tells you that the calculation itself must
be done by a person. Nothing changes in the Legal chat, which arrives at
go-live.

The rest of this release is maintenance behind the scenes. The maintainers'
safety test now also fails when General declines too many ordinary questions
in one area (deadlines, Sentencing Guidelines ranges, or sentence credit),
measured against the rate it declined them at over five recent nights. The
maintainers' test questions gained two kinds, each read by a reviewer before
use: questions that ask an overruled Supreme Court decision's rule as if it
still governed, whose right answer says it was overruled and by which
decision; and questions about how one court treated another's decision,
now drawn from the whole collection of court decisions rather than a small
sample of it. A computer setup can now name the set of
court records it installs, so a trial setup's records never become the main
setup's. None of this reaches the chats you use.
