# GIDEON v0.3.178

Template: 3

## What is new

Nothing user-visible in the chat. Behind the scenes, each release is now
signed by the project's release key, and an upgrade checks that signature
before it installs anything, refusing a release the key did not sign; this
release is the first one signed, and the next is the first whose upgrade
checks it. An install now checks the Docker package key against its
published fingerprint before trusting it. The case-law reader now finds a
judge's name in more of the ways an opinion's author line is written, so
more opinions are credited to their authors. Stopping the nightly
evaluation run at the end of its window now stops all of its parts, and the
build server's test runner gives up its last broad administrator rule.
