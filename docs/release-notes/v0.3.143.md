# GIDEON v0.3.143

Template: 3

## What is new

Nothing user-visible. Before installing or upgrading, GIDEON checks that the
box has the graphics cards its configuration was tested on. That check now
accepts every edition of the card by name — the server, workstation, and Max-Q
workstation editions of the NVIDIA RTX PRO 6000 Blackwell alike — where before
it accepted only the exact spelling of the box's own edition. A different card
is still refused, and the refusal now names both the card found and the card
required. Nothing changes in how anyone uses General.
