# GIDEON v0.3.111

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, the chat model
now reaches the other programs on the box that share it over a network of its
own, so those programs see the chat model and nothing else of GIDEON's. An
install that would rebuild that network while another program is still on it
now stops before changing anything and names that program, instead of failing
halfway. Installing this release restarts every part of GIDEON once, the chat
model among them, so the chat is unavailable for about three minutes.

## What was bumped

No pin moved since v0.3.110.

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.
