the chat, ask a question, and delete their conversation afterwards now share one
piece of code where each used to have its own copy, and their messages are
unchanged. One detail of an internal test record is now consistent between them:
where a check saw two reasons for flagging an answer, it records the reason that
explains the answer's label.
