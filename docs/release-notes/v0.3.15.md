# GIDEON v0.3.15

Template: 3

## What is new

The GPU dashboard shows how fast the engine answers, in tokens per second, over
the dashboard's time range. The GPU memory chart now reads in GiB, where it used
to show a full card as a few KiB. The queue chart is renamed "Requests waiting
and running", the two lines it draws. The GPU temperature chart draws each GPU's
own maximum operating temperature as a dashed line, so a card running hot shows
against its limit; the cure for a card near that line is the room's cooling.
