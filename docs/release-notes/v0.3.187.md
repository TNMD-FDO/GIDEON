# GIDEON v0.3.187

Template: 3

## What is new

Nothing changes in either chat. This release is maintenance behind the scenes.

The box's monitoring pages read more truthfully. The evaluation page's tables
now fit their cards at common screen widths, with every row reachable, and its
two charts are easier to read. The search page's chart of embedding requests now
shows how many requests the server is actually working on. It replaces a figure
that always read zero, and drops a cache chart that always read zero for the
same reason. The automated quality checks now name the figure that failed a
safety-check case instead of reporting the failure bare, and they stop
misreading a legal citation's section number as a sentencing figure. A stopped
check run now deletes the conversation it had open under its test account
instead of leaving it behind. None of this reaches the chats you use.
