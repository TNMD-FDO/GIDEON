# GIDEON v0.3.190

Template: 3

## What is new

Nothing changes in either chat. This release is maintenance behind the scenes.

Restoring the database to a chosen moment now works after an earlier restore.
Before, a restore to a moment after a previous restore could not reach that
moment: it stopped the service, ran for half an hour, and left the database
unable to start. Now it follows the backup history to that moment. When no
backup can reach it, the restore refuses at its first step, while everything
is still running, and names the full backup to take first. The operating
system's automatic library updates no longer restart GIDEON's own services.
Before, an update could cut a night's backup off mid-copy and leave it holding
the server for hours. The maintainers' 300-sheet review of the document
splitter now goes out as a spreadsheet a Windows machine opens, and comes back
checked before anything is written. None of this reaches the chats you use.
