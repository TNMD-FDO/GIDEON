# GIDEON v0.3.151

Template: 3

## What is new

Nothing user-visible. The monthly backup drill now checks two things it used to
skip: it hashes every stored document in the newest backup against its name,
and it reads one passage of text back from the restored backup and checks it
against its recorded fingerprint. A drill that runs while documents are being
written now reports the small difference in row counts instead of failing. The
drill takes a few minutes instead of about one.
