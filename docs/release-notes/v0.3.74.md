# GIDEON v0.3.74

Template: 3

## What is new

Nothing you can see in the chat has changed. Every Monday morning the system now
checks whether CourtListener has published a newer case-law collection than the one
installed. It downloads nothing and changes nothing: when a newer collection appears,
the operator receives one email, and the weekly report of things waiting on a person
lists it until the collection is updated in a window the operator chooses. Upgrading
to this release restarts the chat service and the monitoring dashboards for about a
minute.

## What was bumped

No pin moved since v0.3.73.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
