# GIDEON v0.2.93

Template: 3

## What is new

Nothing you can see in the chat has changed. A new runbook,
`docs/runbooks/model-upgrade.md`, sets out how a newer revision of the chat's
model reaches the office. A person decides at each step, on the record, and
nothing merges or tags on its own. The new model is measured on the build box
in an announced window, weighed against the one it would replace, and taken
only if it does not do worse. At any step the box can go back to the model it
had before. An office receiving such a release takes it with its usual upgrade.
