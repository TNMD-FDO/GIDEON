# GIDEON v0.3.35

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON now runs the store that
will hold the search index for the Legal chat. It is locked with its own key,
reachable only from GIDEON's other services, watched on the monitoring
dashboards, and empty until the index is built. It holds nothing that is not
built again from the court documents, so it is not part of the nightly backup.
Installing this upgrade starts the store and restarts, for a few seconds each,
the monitoring dashboards and GIDEON's own service behind the chat.
