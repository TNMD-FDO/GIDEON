## What is new

Nothing you can see in the chat has changed. On the build box, the command that
downloads the AI models can now also download a trial model that the release's
model file names, keep it next to the models the chat uses, and delete it when
the trial ends. Offices receive no trial models, so nothing on an office server
changes.
