# GIDEON v0.3.194

Template: 3

## What is new

An answer from General that lists the Sentencing Table's criminal history
points row by row now reaches you. Before this release, the safety check could
replace it with its refusal to compute a Guidelines range. A single row, or rows
whose categories repeat or run backwards, still gets that refusal.

The Legal chat's case index will mark fewer cases as overruled by mistake. A
court that overrules an objection, motion, contention, or assignment of error is
no longer read as overruling the case cited for it. On a public test set of
court decisions, 284 of the 285 overrulings it reported were correct. The change
takes effect when the index is next rebuilt. The current index is unchanged.

The rest is maintenance behind the scenes. The maintainers' test questions on
how one court treated another's decision now state any limit the court set. Two
kinds of draft that misread the court are now discarded before a person reviews
them. Test questions about an overruled case now show the passage where the
later court overrules it. Contributors now have one style guide for public
documents, and a check that holds each sentence to 30 words. None of this
reaches the chats you use.
