# GIDEON v0.3.186

Template: 3

## What is new

Nothing changes in either chat. This release is maintenance behind the scenes.

The box can now let go of a search index that was built but never put in
service: the operator retires it by name, and the index clean-up then frees
its disk space at once, instead of waiting the seven days that protect an index
that once answered questions. The first use freed a trial index of about
1.2 million passages. The project's automated checks also stop reporting a
failure when the box is held for maintenance, and the shared record of how
GIDEON and Gideon Transcribe divide the box was brought up to date by both
operators. None of this reaches the chats you use.
