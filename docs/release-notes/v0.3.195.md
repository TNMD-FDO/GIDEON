# GIDEON v0.3.195

## What is new

Nothing changes in the chats you use. This release rewrites the public
documents that describe GIDEON and how it is installed, and updates monitoring
and build components on the server.

The README now opens by saying what GIDEON is and where it runs, and it points
to a new command reference, which lists every `gideon` command and build tool
with what it does, who runs it and when, the exact command line, and the
runbook section that holds its steps. The install runbook and the start-here
card were rewritten sentence by sentence without changing a step, a heading, or
a command. A short page for the office describes what comes next for GIDEON,
taken from the project's roadmap. The contributors' style guide now asks for
plain explanatory paragraphs in place of a fixed sentence length, so the check
that held each sentence to 30 words is gone.

The maintainers' test questions about a case a later court overruled now number
26, past the planned 25. Their expected answers state the overruling decision and its
year in a fixed sentence written by code, and a passage that stops in the middle
of a sentence is discarded before a person reviews it.
