## What is new

General's web search now asks Mojeek as well as Bing and Wikipedia. Mojeek
adds results for questions that Bing answered alone before. Google can still
be turned on by an office and is off by default. Qwant cannot be turned on.

GIDEON can now show a banner at the top of the chat screens, and it sets and
clears that banner itself. Nobody adds or removes a banner by hand, and a
banner added by hand in the chat screens' settings is removed.

A CSA records a coming maintenance window once, with its start and end. From
that moment users see a banner naming the window, which they can dismiss.
While the window is under way, a banner says GIDEON is unavailable, and it
returns at every page load. Both disappear when the window ends. When a
window is moved or withdrawn, the banner changes to match.

An upgrade, a rollback, a restore, or a change that restarts a service a chat
depends on now raises its own "unavailable right now" banner before it takes
GIDEON down. The banner clears when the command finishes, and also within a
minute if the command is stopped partway through.

The rest of the release changes how the project measures its own search
quality. A rollback also no longer leaves a newer release's scheduled jobs
running.

## Trial profile

The trial profile `1x32v-120d` is for a one-card office. It needs one card with
32 GB of memory, either an NVIDIA RTX PRO 4500 Blackwell or an NVIDIA GeForce
RTX 5090, plus 120 GB of host memory and 600 GB of data storage. How the
GeForce RTX 5090's driver behaves and how containers reach it have not yet been
checked. The profile serves the generator `google/gemma-4-12B-it-qat-w4a16-ct`
and the embedder `Qwen/Qwen3-Embedding-0.6B`, whose vectors are their own space,
`qwen3-embedding-0-6b-1024-bf16`, never the reference's. The generator reads up
to 262,144 tokens and the embedder up to 4,096. The embedder shares the
generator's card, and no card memory is set aside for another application. Its
corpus line covers the Supreme Court alone.

The profile was evaluated on the project's own card, capped to the trial's
share of memory: `general-smoke` run `27b852e5-46d3-41b8-a01d-90871b49a680`,
`judge-triples` run `9bd08f25-3d99-4ad1-9bfe-7d47bf4937f8`, and `guardrails`
run `a8c9fae2-01fc-42eb-8333-dc2ca169ede4`, each passing. Neither admitted card
has been evaluated yet. This profile's quality claim rests on these runs, never
on the reference's. No office installs it before v1.0.0.
