## What is new

Nothing you can see in the chat has changed. GIDEON now runs a service of its own alongside the model, which later releases will move General's answers through so that the checks GIDEON makes are made in one place rather than inside the chat window. For now it only answers which model is available, and nothing you type reaches it.
