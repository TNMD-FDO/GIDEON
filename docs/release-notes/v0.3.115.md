# GIDEON v0.3.115

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind it, the rules that notice
when one court opinion says another was overruled, abrogated, superseded, or
disapproved have been measured against a public set of 2,400 labelled legal
sentences: they were right in 285 of the 286 cases where they fired. That
clears the bar set for them, so those findings are now allowed to mark a case
as needing caution once the Legal chat shows treatment, which arrives at
go-live. The rules also now read hyphenated spellings such as *over-ruled*,
and no longer mistake a court overruling an objection or a motion for a court
overruling a case. The next corpus install records the findings under the new
rules beside the old ones. Installing this release restarts the background
worker and the monitoring dashboards briefly; the chat is untouched.
