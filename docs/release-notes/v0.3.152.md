# GIDEON v0.3.152

Template: 3

## What is new

Nothing user-visible. GIDEON can now build the keyword half of a case-law
search index from the case law it has already loaded: `gideon index build
caselaw` writes every passage into the search store, keeping citations such as
"18 U.S.C. § 924(c)" and "Fed. R. Crim. P. 11" searchable as written, and
checks that each stored passage matches the court's text exactly. Running it
again adds only what is missing. The meaning-based half of the index, and the
step that puts an index in front of users, come in later releases; the Legal
chat does not read this index yet.
