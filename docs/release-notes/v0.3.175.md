# GIDEON v0.3.175

Template: 3

## What is new

Nothing user-visible. Behind the scenes, the case-law record now keeps each
opinion's case name in a field of its own, ready for the search index built
after this release; the evaluation checks gain gates over an index build's
counts and over gold passages dropped by a build; a comparison between two
evaluation runs now declines to give a verdict when too few distinct groups
of cases stand behind it; and the tools that run the box now name what is
holding the box's shared locks.

## What was bumped

No pin moved since v0.3.174.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
