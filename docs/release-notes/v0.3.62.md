# GIDEON v0.3.62

Template: 3

## What is new

Nothing you can see in the chat has changed. When the server is prepared, GIDEON
now refuses to place its data disk over a `/data` folder that another application
already uses, rather than hiding that application's files; the refusal names the
folders it found and points to a new section of the install runbook for moving them
onto the disk by hand, in an announced window. No service an office runs is
restarted.

## What was bumped

No pin moved since v0.3.61.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
