# GIDEON v0.2.18

Template: 2

## What is new

Nothing you can see in the chat has changed. This release is for the people who check GIDEON's quality before a change reaches you. GIDEON can now have the model it already runs read an answer beside a known-good answer and say how close the two are, with a short written reason for its grade. That grade is a reading aid, never a verdict: nothing passes or fails a release because of it, and the checks that do decide are still plain arithmetic. The first use of it is a small set of made-up practice questions that measure the grader itself rather than anything you would ask.
