# GIDEON v0.2.29

Template: 2

## What is new

General's chat page now talks to GIDEON's own General service instead of talking to the language model directly. Everything that protects an answer — the arithmetic guard that refuses to state a computed deadline or Guidelines range, the withholding of the model's private reasoning, and the "General does not verify citations." reminder — now happens in one place that GIDEON owns, rather than in three pieces attached to the chat page. Nothing about what is allowed or refused has changed; only where the work happens.

Three things you would notice, if you were using the box today:

- **A blocked answer now keeps what you had already read.** When the guard stops an answer, the text that had already appeared on your screen stays, and the answer ends with the refusal underneath it. Before, the whole answer was wiped and replaced. Nothing that the guard caught is ever shown — it never was — but you no longer lose the paragraphs that came before it.
- **The "Thinking…" indicator opens again.** General takes a moment to reason before it answers, and the page again shows that it is working instead of sitting silent. The reasoning itself is still never shown and never stored.
- **Everything else is the same.** Signing in, the chat list, web search and its confirmation, uploaded files, and the wording of every refusal are untouched. Stopping an answer still frees the machine immediately, and an answer you walk away from still finishes and is waiting in the chat when you come back — both checked on the box for this release.
