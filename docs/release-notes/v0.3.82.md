# GIDEON v0.3.82

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON now writes down, once, which of
the server's two graphics cards each of its AI models runs on, and keeps them there.
Before, a hardware change could quietly move a model onto a different card the next
time GIDEON was upgraded. Now, if a card GIDEON was using is replaced or removed, the
upgrade stops and says which card is missing and how to record the new ones. Upgrading
to this release restarts the monitoring dashboards for about a minute.
