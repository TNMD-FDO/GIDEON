# GIDEON v0.3.70

Template: 3

## What is new

Nothing you can see in the chat has changed. Setting up or upgrading GIDEON now
changes six server-wide settings only while they are still at the operating
system's original value: the time zone, how people sign in over SSH, the
firewall's default for incoming connections, how the system log is kept, the
automatic security updates, and where container images are stored. When another
app has already changed one of them to a value GIDEON can work with, GIDEON
leaves it as it is and mentions it. When the value falls short of what GIDEON
needs, the setup stops before changing anything and names the setting, the value
it found, and the value GIDEON needs, so an administrator can agree one value
with the other app's operator. Where an earlier setup's SSH rule never took
effect, it does now: signing in over SSH needs a key, and a password is no longer
accepted. No service an office runs is restarted.
