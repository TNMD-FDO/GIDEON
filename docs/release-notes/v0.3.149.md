## What is new

Nothing user-visible. The nightly backup's record of how long it ran now covers
the whole run, including writing the set's record and removing old sets, so the
Backup dashboard's duration panel shows the backup's real length. Earlier runs
keep their shorter figure, so the panel steps up at the first backup after this
release.
