# GIDEON v0.3.166

Template: 3

## What is new

Nothing user-visible. Every build of the case-law search index now finds the
passages that recur nearly word for word across opinions, groups each set under
its earliest occurrence in the highest court, and marks a set that
recurs in 25 opinions or more as boilerplate, such as a recited standard of
review. Every passage stays searchable; the grouping and the mark are what a
later release reads to show one copy of a repeated passage and to rank recited
language below a holding.
