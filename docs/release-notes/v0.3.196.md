# GIDEON v0.3.196

Template: 3

## What is new

Nothing changes in the chats you use or on the server. This release rewrites
the public documents in plain explanatory paragraphs, and no step, heading,
section number, or command in them has changed.

The README now explains what GIDEON is and why it runs on an office's own
server without sorting its readers, and it folds the old "Who it is for"
section into that opening. The start-here card, the command reference, and the
contributing, security, and developer guides were rewritten the same way, and
the overview had a pass for vocabulary only. Each runbook the public copy
carries was also rewritten so that every section says what it is for and why
its steps run in their order: backup and restore, observability, release
files, built images, model upgrades, office services, the guardrail review,
and the feedback packet. The install runbook's introduction and first four
sections are rewritten here, and its remaining sections follow in a later
release.
