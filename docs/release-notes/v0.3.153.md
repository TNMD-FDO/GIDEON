# GIDEON v0.3.153

Template: 3

## What is new

Nothing user-visible. The Library of Congress table of Supreme Court decisions
the Court has overruled now travels with each release of the law GIDEON
holds. Its website turns away automated downloads, so at each update the
person preparing the release saves the page from a browser, and the release
carries that saved copy beside the case law; an office installing the update
receives the table with it and downloads nothing for it. An update refuses a
saved table older than the case law it ships with. The Legal chat does not
read the table yet; a later release uses it to flag overruled Supreme Court
cases.
