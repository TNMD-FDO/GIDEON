## What is new

Nothing you can see in the chat has changed. On the development server alone,
GIDEON can now try one proposed change to how it grades its own answers beside
the setting it ships with, on its test copy, and record both results side by
side for the developer to compare. An office's server carries the new setting
file but never runs it, and nothing an office's users see depends on it.
