# GIDEON v0.3.102

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, an office can
now name the address range Docker builds its internal networks from, so a
short-lived test network on the box can no longer take the address of an
office server, such as the mail relay, and cut the box off from it while the
test runs. The range is a new, optional setting the office chooses, kept clear
of every network the office uses. Unset, nothing changes.

New site keys: `docker_address_pool`. Add it to the site file only after this
release's upgrade has finished, then run provision, which applies it by
restarting Docker once, so every service on the box restarts for a minute or
two; do that in an announced window. Before rolling back across this release,
take the key out of the site file first. The steps are in the install and
upgrade runbook, sections 2, 3, and 10. Installing this release restarts the
monitoring dashboards briefly; the chat model is untouched.
