# GIDEON v0.2.22

Template: 2

## What is new

Nothing you can see in the chat has changed. Until now the arithmetic guardrail — the check that stops General from handing you a computed deadline, a Guidelines range, or a release date as though it were reliable — ran only inside the chat page. This release moves that check into the service that answers General's questions, so it runs over every answer the model gives, whichever way the answer is asked for. Two things follow from having it there. When the check stops an answer, the service now also stops the model generating, instead of leaving it working on text nobody will ever see. And the model's private working-out, which it produces before the answer proper, no longer leaves the service at all.

Nobody is using General through the chat page yet, so none of this changes what you would see today; it is the groundwork for the change that does.
