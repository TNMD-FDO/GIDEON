# GIDEON v0.2.92

## What is new

Nothing you can see in the chat has changed. When improvement proposals are
waiting on this server, the office's alert recipients now get one short email a
week, on Monday morning, saying how many are waiting and naming the command that
lists them. It carries no other detail. It is not an alert: nothing is broken, and
the box status does not list it as needing attention. The same count appears on
the Eval board. When nothing is waiting, no email is sent.
