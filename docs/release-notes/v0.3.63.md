# GIDEON v0.3.63

Template: 3

## What is new

Nothing you can see in the chat has changed. GIDEON's background job worker now
reports how many jobs are waiting and running, and the administrators' Overview
board shows a tile for it beside the other services; a stopped or stuck worker
pages the administrators as any core service does. Applying the release restarts
the monitoring services and the worker, and no service a chat turn passes through.

## What was bumped

No pin moved since v0.3.62.
