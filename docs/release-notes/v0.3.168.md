# GIDEON v0.3.168

Template: 3

## What is new

Nothing user-visible. Every build of the case-law search index now records, for
each case the corpus holds, whether later decisions have treated it badly: a
case another decision overruled, abrogated, or superseded is marked as such, a
case only a non-binding court spoke against is marked for caution, and every
other case is unchecked. The mark is kept with the index it was built for, so
it always describes the same corpus the search answers from. A later release
reads it to warn beside a cited case.
