# GIDEON v0.3.169

Template: 3

## What is new

Nothing user-visible in chat. The administrator's `gideon index report` command
now shows what is in GIDEON's case-law collection: the corpus versions on record,
each search index built from them and its state, and, for the index in use or one
named, how many opinions each court holds by status, text format, and precedential
status, how many can be pin-cited, and how many recur as boilerplate. It reads
counts alone and changes nothing.
