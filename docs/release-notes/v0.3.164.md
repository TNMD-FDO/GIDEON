# GIDEON v0.3.164

Template: 3

## What is new

Nothing user-visible. Every build of the case-law search index now leaves a
report behind: per court, how many opinions arrived ready or failed, whether
they are published or unpublished, where their text came from, how many can be
pin-cited, and how closely their citations agree with CourtListener's. A court
that arrives mostly unusable is a number to read before a new index is put in
front of anyone.
