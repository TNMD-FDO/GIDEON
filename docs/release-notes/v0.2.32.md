## What is new

Nothing you can see has changed. This release is entirely inside the project's own
tooling: the weekly check that looks for newer versions of the software GIDEON is built
on can now read the version name of the base image GIDEON's own service is built from,
so that check runs clean again instead of reporting a failure every week. Nothing about
the chat, its answers, or its coverage moves.
