# GIDEON v0.3.191

Template: 3

## What is new

Nothing changes in either chat. This release is maintenance behind the scenes.

The maintainers' test questions about how one court treated another's decision
are now built more carefully. Each such question now names exactly what the
quoted passage shows: which opinion acted, in which part of that opinion, what
it did, and to which case. When an opinion only recounts what another court
did, the question now says so, and names that other court's decision as the
one that acted. Passages that cannot answer such a question cleanly are set
aside before any question is drafted: an "if" or a "would", an actor the text
does not name, or a citation that sits nearer the verb than the case in
question. A reviewer reads every question before it is used, as before. None
of this reaches the chats you use.
