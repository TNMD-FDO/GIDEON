# GIDEON v0.3.113

Template: 3

## What is new

Nothing you can see in the chat has changed. Behind the scenes, installing the
court opinions now ends with a check of how well GIDEON reads their citations:
the citations GIDEON found in each court's opinions are compared with
CourtListener's own list of which opinion cites which, in both directions, and
the install prints how far the two agree. Where CourtListener lists a citation
GIDEON does not have, the check says whether GIDEON saw the cite but could not
match it to one case, or missed it. CourtListener's list is only a check: it
never adds a citation to GIDEON's record. On the opinions already on the box,
the two agreed on 99 % of GIDEON's citations and 94 % of CourtListener's for
the Sixth Circuit, and on 100 % and 91 % for the Supreme Court. Installing this
release restarts the background services briefly; the chat model is untouched.
