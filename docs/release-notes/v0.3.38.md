# GIDEON v0.3.38

Template: 3

## What is new

Nothing you can see in the chat has changed. The chat program is now pointed at
GIDEON's own search store with a key that can only read, so it can never write
anything of its own into it; in ordinary use it does not consult the store at
all. Installing this upgrade briefly restarts the chat page and GIDEON's
connection to it; nobody is signed out.

## What was bumped

No pin moved since v0.3.37.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

## Next maintenance window

No maintenance window is announced. The box has no users until go-live, when that
tag's note announces the first window.
