## What is new

Nothing you can see in the chat has changed. This release fixes the loading of
court opinions: an opinion whose footnote is printed before the part of the
opinion that refers to it stopped the whole court's load. Such opinions now
load like any other, so the first SCOTUS and Sixth Circuit load can finish.

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.
