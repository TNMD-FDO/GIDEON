## What is new

Nothing you can see in the chat has changed. This release changes the project's
own tests alone: the list of the box's services is now written down once in the
tests, and every other test reads it from the same place the box's configuration
is built from, so adding a service later touches fewer files. The box's software
and its configuration are unchanged.
