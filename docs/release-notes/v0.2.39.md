# GIDEON v0.2.39

Template: 3

## What is new

The check that stops the chat from computing a deadline or a sentence date no
longer mistakes a rate, such as "ten days of credit for every thirty days served",
for a computed figure while the answer is still arriving. Such an answer was
already correct when it finished; now no part of it on the way can be read as a
computation either. Nothing else you see in the chat changes.

## What was bumped

No pin moved since v0.2.38.

## Coverage

General only; the Legal chat arrives at go-live on SCOTUS and the Sixth Circuit.

tag's note announces the first window.
