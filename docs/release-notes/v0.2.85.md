## What is new

Nothing you can see in the chat has changed. The team's quality checks can now
compare two versions of the system fairly: they run the same questions five times
over a weekend and report whether one version refuses fewer ordinary questions
than the other, or whether the difference is too small to tell. A check still
running when its night or weekend hours end is stopped at 06:00 and reported
as incomplete, so it never runs into the working day.
