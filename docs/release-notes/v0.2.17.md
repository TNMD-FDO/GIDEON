# GIDEON v0.2.17

Template: 2

## What is new

Nothing you can see in the chat has changed. This release is for the people who check GIDEON's quality before a change reaches you: the test suite now keeps a written record of which of its questions GIDEON got right at the last release, and every later check compares against that record question by question. A question that used to come out right and no longer does now stops the release and is named, instead of being hidden inside an average that still looks fine.
