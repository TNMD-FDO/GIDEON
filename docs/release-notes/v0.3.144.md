## What is new

Nothing user-visible. The rules for sharing the server with Gideon Transcribe
change: the language model's processing is no longer divided between the two
applications by the clock. GIDEON's own work runs first at any hour, and
Transcribe's requests run alongside it, more slowly while GIDEON's work runs but
never refused. Nothing changes in how anyone uses General.
