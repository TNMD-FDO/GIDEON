## What is new

Nothing you can see in the chat has changed. The test copy of GIDEON that
runs beside the office's own, which the developer and the automatic checks
use and no office user ever reaches, now has its own two search indexes, the
ones document search will use. They are built the same way as the office's,
so a later release can try a search there before it reaches the office. The
office's own GIDEON is untouched by this release and restarts nothing.
