# GIDEON v0.3.181

Template: 3

## What is new

Nothing user-visible in the chat. Behind the scenes, every case-law opinion has
been read again under the improved reader from recent releases, so the stored
layout of each opinion now matches what the reader makes of it, and each
opinion now records whether it was issued per curiam. An opinion whose text
reaches GIDEON as unreadable scrambled characters is now set aside as
illegible instead of being stored as if it were readable. Restoring from a
backup now picks its point in time and records its boundaries more reliably.
A plain-words overview of what GIDEON is and how it works has been added to
the project's documents.
