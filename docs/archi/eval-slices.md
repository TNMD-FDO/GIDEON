# The eval slices and their measures — architecture leaf

**Read this when** implementing the extraction grammar, its contract, or its measure, a variant axis, the judge or a judge prompt, the judgments file, the `judgments` metrics, the ranked-list file, or a slice's runner; the harness a runner sits behind — the set and its loader, the slice registry, the run record, the reference, and the two `eval` commands — is [`eval.md`](eval.md)'s. The map is [`../ARCHI.md`](../ARCHI.md); its §8 table names every command's leaf.

## Commands

- **`python3 -m tools.variants <parents> <variants> [--series <file>] [--series-file <file>] [--sheet | --write --reviewer <id> --on <date>]`** (§18.2; a development tool, never shipped and never imported by `gideon/`): with neither mode it *checks* — every committed variant re-derived from its parent line by line, a missing pair the exit code. `--sheet` prints the pairs for the human read; `--write` appends them, and only then, carrying the reviewer id and date it is given. Invariants: an axis edit is applied to the labelled objects alone and a variant that cannot preserve its parent's labels is refused rather than written; the ids come from the whole series, which `series.txt` beside the cases names, and a `--write` whose manifest names a file it cannot see refuses rather than mint an id twice.
- `eval run`, whose `ranked` stage reads the ranked-list file and whose `run` stage calls a slice's runner, and `eval reference` are [`eval.md`](eval.md)'s.

## Release constants by module

- `gideon/extraction/contract.py` — the type vocabulary and its keyed and section-like subsets; a type is never renamed.
- `gideon/extraction/grammar.py` — the grammar's version, the pattern registry, the bare-section cue list, and the appendix compilations' table; a pattern whose behaviour changes takes its next `@N`, and the version moves with any pattern.
- `gideon/extraction/scoring.py` — the gate's two bounds (§11.2).
- `tools/variants/axes.py` — the axis registry, each axis versioned `<name>@<N>`, and the types an axis respells; an axis whose edit changes takes its next `@N`, and a committed variant keeps the version it was written under.
- `gideon/evaluation/judge.py` — the closed failure-mode vocabulary, the verdict schema and its reason bound, the token reserve and the request bound (ADR-0017 starting values), the prompt registry keyed `name@N`, and each registered version's pinned digest; a prompt whose text or schema changes takes its next `@N` and a new digest, and an edit under the same id is red.
- `gideon/evaluation/judgments.py` — the judgments file's relative name under a set root, the line's ordered key tuple, the grade scale's bounds, and the attorney-role pattern (a subset of `evalset.py`'s role pattern); a key is never renamed.
- `gideon/evaluation/rankmetrics.py` — the definition id, the depths of nDCG, Hole, and recall, the relevant grade, the overlap threshold, and the ranking floor; a landed definition id is never edited.
- `gideon/evaluation/ranked.py` — the file's and the entry's ordered key tuples, the findings' fixed file label, and the refusals' fix; a key is never renamed.
