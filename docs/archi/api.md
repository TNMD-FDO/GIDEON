## Commands

- **`python -m gideon.api`** (`gideon/api/__main__.py`): reads the environment and both mounted secret files, refuses a missing or empty value, then runs the Starlette application under plain uvicorn. `/health` is unauthenticated and does not contact the engine; `GET /v1/models` requires the bearer key, passes the engine's status and body through, and returns a fixed 502 body on transport failure. The pure ASGI middleware logs only the method, matched route template, status, and elapsed seconds.

`POST /v1/chat/completions` is the frontend's own connection since general-turn ticket 09 ([`../frontend-contract.md`](../frontend-contract.md)): the render points Open WebUI's one OpenAI-compatible connection at this service by hostname, carries the connection's own key to it, and renders `ENABLE_FORWARD_USER_INFO_HEADERS` on in its plain form, so the seat's identity reaches the service in headers and never the engine. The endpoint sends the caller's body bytes and `Content-Type` to the engine unparsed — the model id and every other field pass by construction, the bearer becomes the engine's key, and no other caller header is forwarded, though one is now read — and judges what comes back. The request's own body is read once for the judged state: `stream_state_from_body` builds the guardrail's `StreamState` from the caller's `messages`, and a body with none readable still judges, on a context of its own. **The engine's answer decides the shape, never the request**: a 200 whose media type is `text/event-stream` — the text before any `;`, trimmed, compared without regard to case, so the engine's `; charset=utf-8` reads as a stream — is relayed one `aiter_raw()` chunk per body message with the engine's content-type header as sent and no length; anything else is read whole and returned under the engine's status, content type, and bytes. A transport failure or timeout before the headers, or during a whole read, is the fixed 502; a failure after a stream has started sends a blank line, the same error object as one `data:` event, the end marker, and a clean end, and names the failure by its exception class alone on `gideon.api.relay`. The endpoint is a pure ASGI callable — Starlette takes a non-function endpoint as an ASGI application — and runs its work in an `anyio` task group beside a task blocked on `receive()`: whichever finishes first cancels the group, so a caller's hang-up cancels the upstream wherever it is suspended and httpcore closes the connection under its own shield, which the engine reads as its client going away. The watch is the service's own, independent of the ASGI `spec_version` the server advertises, and it is the scope the lag window and the trip sit inside. The upstream response is closed in the exit path under a shielded scope.

**The judged stream.** `gideon/api/sse.py` reassembles events over `aiter_raw()`'s chunks — a chunk is never assumed to be an event, or even a whole character — and `gideon/api/judged.py`'s `StreamMechanics` judges each one: `content` is released through the shared module's lag window, a reasoning delta under any of the three names is withheld and never relayed — except that the turn's first one is replaced by the module's fixed placeholder, relayed once under the engine's own key so the pinned frontend opens its reasoning block over an empty body and a seat does not watch a silent wait (slice-1 ticket 37's shape, restored at general-turn ticket 09 when the cutover first put a frontend on this connection) — and a relayed choice carries `index` and `finish_reason` with a delta of `role`, `content`, and `tool_calls` alone, so the engine's `logprobs` and its own extras are dropped. On a trip the relay closes the engine's connection first and only then sends the tripped family's refusal, after the released prefix and the module's separator, and ends the stream as the engine ends any stream: a finish chunk under `stop`, then the end marker. A trip's `created` and `id` are the engine's envelope, never minted, and with no envelope seen none is sent. The four unfinished ends — the end marker with no finish chunk, a clean end without one, a transport failure, and the engine's own `error` event — each settle the held tail before what follows, and a usage chunk after the finish chunk passes. **The citation label is decided where the tail settles** — the finish chunk and `_settle_tail`, which the other four ends all reach — so all five untripped ends carry it and a trip reaches the step at none of them. Once the tail has settled, the finished answer is read from the window's own content entry, which only `content` deltas ever enter, and `stamp.tail_for`'s tail joins the last text released: inside the finish chunk's content after the held tail, in the settled tail's chunk on an unfinished end, and as a text chunk of its own only when nothing is held. The engine's chunk sequence is unchanged and a citation-free stream is byte for byte what it was; the `finished` flag decides once, so a usage chunk or the end marker after the finish chunk adds no second label.

**The whole completion.** A non-streamed body is judged whole by `judge_completion` and answered whole, the refusal in place of a tripped answer, reasoning stripped from the message, `null` content and several choices each carried, and a text content that did not trip gaining the tail `stamp.tail_for` owes it. A body the judge cannot read is the fail-closed path: an OpenAI-shaped error object under the code `completion_unjudged`, content-free, with the exception class alone on `gideon.api.relay`. The frontend's task calls — a chat's title and tags, the search's queries — arrive as whole completions on this connection and are judged by the same path, with no branch of their own (contract §2 row 7); the stamp has none either, because no wire fact separates a task call from a whole chat turn, so a citation-shaped task output is stamped after its JSON object and the frontend's own brace slice discards the label (ADR-0045 (b), the maintainer's ruling in general-turn ticket 08).

The request line gained two truths the watch makes necessary: `-` in the status field when no response had started, and the word `disconnected` when the caller left before the response finished — a disconnect arriving after the final body message is the server's own end-of-response signal and is not one.

## Configuration

The service reads `GIDEON_ENGINE_URL`, `GIDEON_ENGINE_API_KEY_FILE`, `GIDEON_API_KEY_FILE`, `GIDEON_API_PORT`, `GIDEON_SOURCE_HEADER`, and `GIDEON_EVAL_IDENTITY`. The URL is the engine's OpenAI base ending in `/v1`; both key variables name Compose secret mounts inside the container, and a missing or empty file refuses startup with its path. The last two are the forwarded header the trip row's `source` word is decided on and the value under it that reads as the eval identity: neither is a secret, neither names a file, and a missing or empty one refuses startup like the others. The audit role's password is a third Compose secret mount with no setting at all — the trip writer reads it at write time from the shared module's constant path, so nothing here reads it at startup; Compose itself refuses a service whose secret source is absent, and a turn must never depend on the record. The API key middleware compares the bearer value as bytes and answers unauthorized requests with an OpenAI-shaped 401 and `WWW-Authenticate: Bearer`.

The image has the pinned Python base and eleven build arguments: `STARLETTE_VERSION`, `UVICORN_VERSION`, `HTTPX_VERSION`, `ANYIO_VERSION`, `HTTPCORE_VERSION`, `H11_VERSION`, `CERTIFI_VERSION`, `IDNA_VERSION`, `CLICK_VERSION`, `TYPING_EXTENSIONS_VERSION`, and `PSYCOPG_VERSION`. The last feeds two wheels, `psycopg` and `psycopg-binary`: the two projects release in lockstep, and one argument makes a half-bump impossible by construction, which matters because a driver the trip writer cannot load fails silently. The build tool's smoke proves it loads on its binary libpq before the push ([`tools.md`](tools.md)). It installs only those wheels, runs `pip check`, and runs as the unprivileged `gideon` user; the repository is not copied into it.

`API_SOURCES` is the checkout-relative package directory `gideon/api`. The render loader walks it through the `Host` seam, ignores `__pycache__` and `.pyc`, and hashes sorted relative paths and texts. The resulting `sha256:` digest is a Compose label, so a source move recreates `gideon-api` by its changed block. `tests/test_service_import_boundary.py` holds every declared Python file to the standard library, the image's five imported dependency roots, or the declared package, keeps `gideon` imports at module level, and keeps the parent initializer to its docstring and `__version__` assignment. The declared set holds the shared judge, `gideon/guardrail.py`, since the service first imported it, and its Postgres driver is one of those five roots, read from `guardrail.TRIP_DRIVER_MODULE`: since general-turn ticket 07 put the driver in the image the deferred-only allowance is gone and the driver is an ordinary image dependency. The host boundary's own rule still keeps the import inside `write_trip_row`.

## Release constants by module

The constants follow [`render-apply.md`](render-apply.md)'s rule: a reader opens the module for the name and value.

- `gideon/api/upstream.py` — the connection and read bounds for the engine client, and the completion's own longer read bound (httpx's read bound is per network read, so a completion silent until it is finished needs it).
- `gideon/api/sse.py` — the incomplete-event buffer's bound and the stream's end marker.
- `gideon/api/judged.py` — the relayed choice, delta, and message keys; the reasoning names and the text names read in order; the chunk object; and the unjudged error's code and body.
- `gideon/api/stamp.py` — the label and its separator, the tail the two together make, the longest text one pattern may match, and the four citation family ids. The text is ADR-0043's sentence and carries no site value (ADR-0028).
- `gideon/api/__main__.py` — uvicorn's graceful-shutdown bound.
- `gideon/host/render/api.py` — the service, image, secret, route, port, mount, working-directory, source, and probe identities shared by Compose, Prometheus, and Grafana, and the three forwarded user-header names (`X-OpenWebUI-User-Name`, `-Email`, `-Role`) that the turn harness's service door fills for the eval identity. `API_SOURCE_HEADER` is the email name under the purpose that reads it — the one the trip row's `source` word is decided on — and the Compose block renders the service's setting from it, so this is the one rendered artifact that reads a forwarded header name. The names stay outside `API_SOURCES`; the value reaches the container through the block.

## Tests

- `test_api_service.py` — settings refusals, the two source settings among them, bearer authentication, health, model-list pass-through, bounded upstream failures, and content-free request logging over `httpx.MockTransport`.
- `test_api_sse.py` — reassembly: an event split at every byte offset, a multi-byte character split across chunks, several events in one chunk, CRLF framing, a comment dropped, and the buffer's bound.
- `test_api_stamp.py` — the stamp module: the seed's family, version, and kinds, two shaped cases per family, and every seed answer reporting its named family or none; the shapes the four families cover and the shapes outside them; every pattern bounded and matching within the ceiling; the module's imports held to the standard library by an AST read, the reason in the failure's message; the label equal to ADR-0043's sentence and free of every value of `config/site.example.yaml`. The decision: the tail owed to a shaped answer and not a free one, nothing owed to an answer already ending in the label under any whitespace, the tail when the detector raises, nothing when it raises over a stamped answer, the tail when both reads raise, and the tail equal to the separator and the label.
- `test_api_judged.py` — the pure mechanics and the window's first tests against the package: every seed positive and control through the mechanics at granularities of one, seven, and word pieces, the large sweeps marked slow; no released prefix trips under `judge_rendered`; every positive trips once with its family's refusal and the controls stay within `len(controls) // 20`; reasoning withheld under all three names and a fourth no list holds; the separator present after a released prefix and absent before one; the finish-chunk tail and the four unfinished ends; each error-path shape, two of them as the stream's first event; the usage chunk passing; and the whole body clean, tripped, reasoning-stripped, with `null` content, with two choices, unjudgeable, and task-shaped; and the source word decided from one header's values — `eval` through its case and padding variants, `user` when the header is absent, empty, repeated, or another's. It also holds the label on both paths: every seed shaped answer stamped once and every free one untouched, whole and streamed at the three granularities; a tripped choice the refusal alone and a second choice decided on its own text; `null` content left and an already-labelled answer unchanged; a task-shaped body stamped after its closing brace, the frontend's brace slice giving the object alone; the label inside the finish chunk with the held text, after the settled tail at each of the four unfinished ends, and as a chunk of its own when nothing is held; a trip before any release, after a citation-shaped prefix, and on a finish chunk whose tail trips, each ending at the refusal unlabelled; a shape in reasoning alone unstamped; and no second label after a usage chunk or the end marker.
- `test_api_completions.py` — the judged relay driven at the ASGI level over a gated stub engine on real chunk shapes: the stream's order and per-event flush, the three content-type spellings, the whole and error paths, both disconnects at ASGI `2.3` and `2.4`, the mid-stream failure's events with the held tail settled before them, the trip's close awaited before the refusal is sent, the read bounds, and the log's additions, content-free. It also holds the row: one per request on both paths with its four values asserted, one for two tripping choices and for a trip then an unjudgeable choice, a connect that raises and a connect held on the test's own event with the response complete and byte-equal while it is still held, and all five forwarded headers sent with sentinel values over clean, tripped, unjudged, and upstream-failed requests, the sentinels absent from every captured log record, from the row, from the response, and from what the stub engine received. The label's order is held here too: a shaped stream's last text message ending in it with the chunk count unchanged, a mid-stream transport failure and the engine's own `error` event each sending the settled tail with the label before their error events, a shaped whole completion stamped and a free one byte-equal to what it was, and no neighbour of the label in any captured record. Every wait is bounded, so a buffering relay fails rather than hangs.
- `test_api_relay_sockets.py` — the same claims through a real `uvicorn.Server`, httpx's real transport, and `http.client` over ephemeral loopback ports, comparing parsed events: the role chunk read while the stub still holds the next, the client's close reaching the stub, and on a trip the stub's connection ending while the client has yet to read the refusal. It is the re-proof CI runs when the pin watch moves the HTTP stack's pins; the box's proof runs once.
- `test_service_import_boundary.py` — the declared-source import and parent-initializer tripwires, including planted violations.
- `test_render_api.py` — the service block, key, probe, rule, source digest, recreation judgment, and GPU/no-GPU rendering, with the two source settings and the audit secret's mount recreating `gideon-api`'s block alone and the top-level `secrets` map equal before and after.
