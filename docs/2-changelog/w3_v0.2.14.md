## Changes

This release implements slice-2 ticket 02 under the plan `docs/1-plans/extraction-grammar-remaining-families-and-variants.plan.md`: the extraction grammar's second half and the frozen set's variants. It is the ticket's **second** cycle. The first built the whole of it, green in its own tree, and was withdrawn at its release because that tree had never met ticket 04's loader (`v0.2.11`); its work was parked on the local branch `wip/extraction-grammar-02-preserved`. This cycle **harvested** that tree rather than regenerating it and **re-seated** the three surfaces that collided. No minor is demanded by spec §2.1: no site key and no `/etc/gideon` contract change.

- **The five families** (`gideon/extraction/grammar.py`, `contract.py`): C.F.R. (`21 C.F.R. § 1308.11`, `28 CFR 2.20`), the appendix compilations (`18 U.S.C. app. 3 § 6`), the habeas rules (`Rule 6 of the Rules Governing § 2254 Cases`, `§ 2254 Rule 6`), the Supreme Court Rules (`Sup. Ct. R. 13`), and docket numbers. Eight patterns join the registry, `usc/bare-section` takes `@2`, the appendix compilations get their table, precedence is resolved by position, and `GRAMMAR_VERSION` moves to 2. On `main` four of these five were a *decline* — the bare forms stood aside inside the construction and nothing was emitted in their place — and a docket number was not seen at all. A habeas rule is never read as a Federal Rule and a Federal Rule never as a habeas rule.
- **The variants** (`tools/variants/`, new — `__init__.py`, `__main__.py`, `axes.py`): a generator that derives a parent case's respellings over ten axes (`code-dotted`, `code-bare`, `code-word`, `sign-present`, `sign-absent`, `spacing-tight`, `spacing-nbsp`, `form-long-short`, `docket-marker`, `lower-case`), each edit applied to the labelled objects alone and each variant's expected objects derived from its parent's labels. With neither mode it *checks* — every committed variant re-derived line by line; `--sheet` prints the pairs for the human read; `--write` appends them and only then, carrying the reviewer id and date. Recall is now measured on how people type and not on forty sentences alone. It lives under `tools/`, which `gideon/` never imports.
- **The frozen slice**: 354 cases in four files, `series.txt` naming them, **273 ids in `slices/extraction/invented.ids` and 81 in `harvest.ids`** — one list per side of the export boundary. `extraction-variants.jsonl` (the harvest's 41 variants) joins `EXCLUDED_PREFIXES` with its paired `.gitattributes` line; `extraction-invented-variants.jsonl` (218) is kept. This is `eval-v1`'s first freeze; from this release the slice changes only by append.
- **The loader learns a third origin** (`gideon/evaluation/evalset.py`): beside harvest and invented, a *variant* — its ordered keys put `parent` between `labels` and `cluster_id`, it carries no `seed`, its labels are exactly `[variant, <axis>@<N>]` with the axis checked for form alone, and the own-id cluster rule is skipped for it, its cluster judged against its parent's. One relational pass beside `_supersedes_findings` refuses a `parent` that names no case, no earlier case of its id series, a variant, or a different cluster — so a dangling parent refuses in `eval run` everywhere and not in pytest alone.
- **The active set in both homes, held equal** (`gideon/extraction/scoring.py` and the loader): `active_cases` takes the parent rule and stays **transitive**, so a corrected parent takes its variants with it; the loader's `active_ids` gains it one step deep, because the slice runner picks its cases from `active_ids` and would otherwise write a `pass` row for a case the scorer never scored. The loader refuses a variant of a variant, so the two agree on every set that loads, and a test holds them equal over the committed set and over a planted chain.
- **The set test re-seated** (`tests/test_extraction_set.py`, from `main`'s text): `v0.2.11` cut 232 lines of shape checking from this module onto the loader and `tests/test_evaluation_set.py`, and the parked test — written before that — extended exactly those regions. The parked test's re-grown duplicates were **dropped, not ported**. What remains is what the loader cannot know: the four byte pins, the one id series, the ten floors, the axis registry's membership, the export boundary's pairing, the Supreme Court paragraph rule, both gates, the residuals, and the scorer's parent cases. `_available_case_files` now reads `series.txt` rather than repeating the file list.
- **The harvest's proof**: thirteen paths came over whole — `gideon/extraction/{contract,grammar,scoring}.py`, `tests/test_extraction_grammar.py`, `tests/test_variants.py`, `tools/variants/`, and the four case files with `series.txt` and the build-gates README — each first proven against `main`'s tip, which still held the merge base's blob for every one of them, so nothing on `main` was reverted by the checkout; the five pinned prefixes recompute to the values the parked test recorded, the harvest's second proof. The files `main` had changed were edited from `main`'s text and never checked out. **Two artifacts are human-gated and were copied, never regenerated**: the 33 invented cases (`extraction-063`–`extraction-095`), relabelled blind by a second model and read by the maintainer, and the 259 variants (`extraction-096`–`extraction-354`), written after the maintainer read the sheet.
- **Criteria**: all four of ticket 02's are ticked; the gate holds precision ≥ 0.95 and recall ≥ 0.90 over the whole frozen set with every registry type gated, and the ticket's proof is the hosted `checks` green on the pushed tag.
- **The residuals within the bounds**: twenty-two, listed by case id and offset in the ticket's close-out comment, read from pytest's warnings summary — the next tuning's input without a rerun.
