## Changes

- **The table** (`migrations/0003_guardrail_trips.sql`): `guardrail_trips` with `id`, `at`, `branch`, `family`, `pattern_id`, and `source` (a CHECK confining it to `user` and `eval`), primary key `(id, at)`, `PARTITION BY RANGE (at)`; `guardrail_trips_ensure_partition(timestamptz)` in `audit_log_ensure_partition`'s shape — `SECURITY DEFINER`, the hardened `search_path`, the schema-qualified partition, owned by `gideon`, revoked from PUBLIC, EXECUTE to `gideon_audit`; INSERT to `gideon_audit`, SELECT to `gideon_ro_metrics`, nothing else; forward-only (ADR-0005), retention the future sweep's (§19.3). `tests/test_stores.py` holds the contract and re-sequences its fake migration past the real 0003.
- **The Filter** (`compose/open-webui/functions/arithmetic_guardrail.py`, frontmatter version 3): `StreamState` carries `branch` (the request body's model id) and `source` (`eval` when `__user__`'s email is the eval identity's, else `user`), both stashed by the inlet before its session gate and required by `_stream_state`; the hook's fallback state for a request the inlet never saw carries `None` and `user`, and a row from it writes the `unknown` marker. `_record_stream_trip` calls `record_trip` right after storing the trip, under its own guard, so every stream trip — the judge's and the hook's own exception — is one row whether or not the outlet ever runs; the outlet calls it only on the route where it judged the message itself and on its own error path, the branch from the state or else the body, and replaces a stream-tripped message without recording again. `record_trip(trip, branch, source)` builds a frozen `TripRow` (the `unknown` marker for an absent branch, `user` for a word outside the vocabulary) and hands it to `dispatch_trip_row`, which starts a daemon thread running `write_trip_row`: the password read from `/run/secrets/postgres_gideon_audit_password` with its trailing line break stripped (apply writes every generated secret with one, `read_secret` strips it the same way), `psycopg` imported lazily inside the function, one connection to `postgres:5432/gideon` as `gideon_audit` with a 3 s connect timeout and a 3000 ms statement timeout, the partition call for `now()` then a parameterized INSERT in one transaction; every exception at any step dropped, nothing logged or printed, never raising. The connection facts, the mount path, the timeouts, the driver name, the source vocabulary, and the marker are release constants beside the pattern families (ADR-0028), held to `audit.py`'s role, `stores.py`'s database, the Postgres service name, and the secret registry's name by a coupling test. The header comment names the one exception to the file's stdlib rule and why; the hygiene test holds module-level imports to the standard library and a nested import to the standard library or the named driver.
- **The mount** (`gideon/host/render/compose.py`, `gideon/host/secrets.py`): `postgres_gideon_audit_password` joins the top-level `secrets` map and the frontend's `secrets` list — the pattern the exporter's, Grafana's, and Postgres's secrets follow — so the frontend's container reads it at `/run/secrets/` as root and a rotation reaches it through a recreate; the registry entry names the frontend's trip writer as the password's second consumer; the drill's document is unchanged. The frontend's block moved, and so did the top-level digest: this apply recreates every service once.
- **The board** (`compose/grafana/dashboards/overview.json`): "Guardrail trips", a bar time series on `gideon-rows` counting `source = 'user'` rows per day and pattern id under Grafana's time filter with its own `timeFrom` of 30 days; "Last eval trip", a stat reading the newest `source = 'eval'` row's age in seconds. `tests/test_render_grafana.py` holds both panels to the datasource, the table, the source filters, and the range; the three render fixtures regenerated (`compose.yaml`, `manifest.yaml`, the board, the Function's content in the apply manifest).
- **Tests** (11 new): the inlet's stash by role and identity; every seed positive over the fake stream at three granularities dispatching exactly one row at its trip chunk with the outlet adding none; the hook's exception path; the outlet's own-judgement row and both fallbacks; the vocabulary rule with fictitious fragments; the writer over a fake connection — the stripped password and every keyword argument, the partition call then the parameterized INSERT inside one context entry, the password in no statement; every failure silent on both streams, the driver's absence forced through `sys.modules`; `record_trip` swallowing a raising dispatch and the daemon thread carrying the row; the constants' coupling; the migration's contract; the panels.
