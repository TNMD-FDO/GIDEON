## Changes

This release implements slice-1 ticket 52 under the plan `docs/1-plans/cancel-generation-after-a-stream-trip.plan.md`. When the arithmetic guardrail's stream hook tripped, it replaced that chunk's text with the refusal and emptied every later chunk's, but nothing closed the engine's stream: the frontend read it to `[DONE]`, and the one shared generator spent the whole answer's GPU seconds on text nobody saw — ticket 34's turn (B) took 269.82 s at `v0.1.18` to a refusal shown near 25 s. The hook now ends the turn from inside itself through the frontend's own Stop path, with no frontend patch (ADR-0001) and no site key.

- **The Filter's cancel branch** (`compose/open-webui/functions/arithmetic_guardrail.py`). `StreamState` gains a `cancel_requested` flag (held in `_stream_state`'s key set and its content-free `repr`). After a trip, the first chunk still carrying a generating choice — a non-empty `choices` list whose first item has no finish reason — calls one total module-level function over the request's metadata: when the metadata carries the frontend's task id (the browser path), it cancels `asyncio.current_task()`, the frontend's registered chat task, and the hook returns nothing, so the chunk is dropped and the cancellation lands at the frontend's next read. The frontend's cancel branch closes the engine's connection (vLLM aborts the request at its next scheduler step) and persists the message as done with what was released: the clean prefix, the separator, and the refusal; the outlet does not run. The trip's own chunk, a finish-only or usage-only chunk, a request without a task id (the direct branch: the harness's managed turns and raw replays), and no running task never cancel, and the hook's never-raise contract holds. The trip's row is still written by the hook at the trip (ticket 11), before the cancel.
- **The turn harness learns the shape** (`tools/turns/classify.py`, `browser.py`, `run.py`). A stored replacement is the refusal alone or a prefix ending in the separator and a refusal; a non-empty prefix is judged by the Filter's own judge first (`leak` with its pattern id) and is otherwise `replaced` from the stream. The browser mode's replacement predicate admits a painted answer ending in a refusal, `LiveEntry` gains `refused`, and the row's live field gains `refused at <s>, ended at <s>` on the page's own clock, whose difference is the cancel's cost; the run record carries `refused_index`, `refused_at`, and `ended_at`. A replaced row's existing `block present` detail now tells the cancel path (the placeholder reasoning item kept) from the outlet's whole replacement (`block absent`).
- **Tests.** `tests/test_arithmetic_guardrail.py` gains a task-form driver on `FakeStream` and a cancel suite over every seed positive at three granularities, padded with a clean tail so each exercises the cancel and unpadded so the finish-chunk trips prove the no-cancel side, plus the negatives (clean, usage-only follow, no task id, no loop) and the record-before-cancel check; `tests/test_turns.py` and `tests/test_turns_browser.py` hold the suffix shape, the widened predicate, and the new verdict fields. The render fixtures are regenerated, the Function's content the change. The gate is green: `ruff`, `mypy` (206 files), and the suite.
