## Changes

ADR-0045 (b)'s last clause, general-turn ticket 08: the citation stamp lives in
General's service. The detection and ADR-0043's fixed label move verbatim from
the outlet Filter into `gideon/api/stamp.py` — the Function's file byte-untouched
and its copy held statement-equal until ticket 09's cutover deletes it — and the
service appends the label itself on both judged paths.

- **`gideon/api/stamp.py`** carries the Function's statements in the Function's
  order and the service's own half: `STAMP_TAIL`, the separator and label as the
  one string every reader appends or strips, and `tail_for`, the stamp's whole
  decision as one function. It owes nothing to an answer already ending in the
  label, the tail to one a shape is found in, and nothing otherwise; its own
  failure fails toward the label, as the Function's fallback does, so it never
  raises and its callers need no guard. It logs nothing — it holds model text
  (§19.4) — and imports the standard library alone, because the turn harness
  imports it on the box's system Python where the service image's dependencies
  do not exist; a test holds that by an AST read.
- **The whole completion**: a choice whose content is text and did not trip gains
  the tail in `judge_completion`'s rebuilt message. A tripped choice is the
  refusal alone, `null` content is left, several choices are each decided on
  their own text, and the unjudged error object carries nothing.
- **The stream**: the label is decided where the window's tail settles, which is
  the finish chunk and `_settle_tail` — the two places that cover all five
  untripped ends, the end marker with no finish chunk, a clean end, a transport
  failure, and the engine's own `error` event among them. The finished answer is
  read from the window's own content entry, which only `content` deltas ever
  enter, so a shape in withheld reasoning is never scanned. The tail **joins the
  last released text**: inside the finish chunk's content after the held tail, in
  the settled tail's chunk on an unfinished end, and as a chunk of its own only
  when nothing is held. The engine's chunk sequence is unchanged and a
  citation-free stream is byte for byte what it was at `v0.2.26`; the `finished`
  flag decides once, so a usage chunk or the end marker after the finish chunk
  adds no second label. A trip returns its payloads before the stamp's step on
  either path and is never labelled. `gideon/api/relay.py` is unedited.
- **A task call's citation-shaped output is stamped on the wire, and the pinned
  frontend's parse discards the label.** `docs/research/owui-task-calls-on-the-wire.md`,
  folded onto this branch from its research branch, read the pin: no body field,
  header, or model id separates a task call from a whole chat completion, and
  `stream` is the caller's to set. The one signal it found under GIDEON's own
  render — a task call carries no `system` message — the maintainer declined: it
  rests on three render choices the frontend contract's §4 layers plan to move,
  and it would leave a bare client's whole completion unstamped, the expensive
  error where the stamp's doctrine makes the miss the failure and a false label
  harmless (§15, ADR-0020, ADR-0043). So every citation-shaped, untripped
  completion is stamped, a task call's among them. What makes that harmless is
  the frontend's own parse: on every live task path — title, tags, search
  queries — it keeps the text between the first `{` and the last `}` and
  discards what follows, so the label never reaches a stored title or tag. The
  ticket's "a task call's output never carries it" is therefore true of what the
  frontend stores and not of the wire. `docs/frontend-contract.md` row 7 carries
  it with its "if it changes" read, which is ticket 09's browser-mode look at a
  title after a citation-shaped turn.
- **The loaders**: `tools/turns/classify.py`'s `own_length` imports the module and
  strips `STAMP_TAIL`, its by-path constant and cache leaving, and the two
  `tests/test_turns.py` sites import it. The turn harness now loads two Functions
  by path, not three.
- **The tests**: the seed, detection, and bounds cases move from
  `tests/test_citation_stamp.py` to the new `tests/test_api_stamp.py`, which adds
  the decision's cases, the standard-library import rule, the two-file equality
  check with both exempt sets named exhaustively, and the held list of files that
  load the Function by path. `tests/test_citation_stamp.py` keeps the Function's
  outlet hooks alone, every detection read the package's, and leaves with the
  Filter at ticket 09. `tests/test_api_judged.py` and
  `tests/test_api_completions.py` gain the whole and streamed stamping, the five
  ends, the trips, the task-shaped bodies, and the label's order at the ASGI
  level.
