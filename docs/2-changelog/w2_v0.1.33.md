## Changes

- **The rule** (`docs/agents/issue-tracker.md`, a Conventions bullet and the new Standing tickets section): a ticket belongs in `.scratch/standing/` when its closing criterion names an event no session can cause — a later slice's tag, an upstream release, a calendar event, a person outside the project; a ticket blocked by another ticket stays in its effort (that is what `Blocked by` is for), and a decision the maintainer can make is `ready-for-human` in its effort. The machine-readable form is the event as a clause of the `Blocked by` line's first sentence, the external blocker `v0.1.32`'s grammar already reads. Two exclusive states: *waiting* while the event clause stands; *fired* once the session that sees the event fire — a triage, a tracker session, the outstanding-items step — replaces the clause with the word `fired` and moves the event, dated, into the parenthesis as provenance, after which the ticket is offered like any other while it stays in the directory. `none` is never a standing ticket's first clause. The move: `git mv`, **committed alone** before the commit that edits the moved ticket; the number kept, a ticket arriving at a taken number taking the next above the directory's highest with `formerly <effort> ticket NN` in its first body line; the ticket's bare pointers qualified with their effort; every live pointer elsewhere corrected to `standing ticket NN`, a dated reference to a past event and a release record keeping the name the ticket had. Worked in place: triaged, claimed, resolved where it is, the path changing once; a new slice's `/to-tickets` reads the directory for tickets whose event is that slice's tag and opens no duplicate (`to-tickets` is a Matt Pocock skill and takes no block, so the rule lives in the document and `CLAUDE.md`). No observations file. The one sentence stating the directory's path is what `tests/test_tracker.py` holds the tool's constant to.
- **The board** (`tools/tracker.py`): `STANDING_EFFORT` names the directory; `parse_blockers` returns a third value — a first-sentence clause that is exactly `fired` (any case, a trailing period allowed) is dropped and recorded, `fired; slice-1 ticket 57` one reference and fired, `none (fired …)` unblocked and not fired; `Ticket` and `BlockerCell` carry the flag; `_reference_map` resolves a number to the first file read in sorted order, so a duplicate never silently overwrites; `_offered_now` admits a standing ticket to the frontier, the decisions owed, and the triage owed in the fired state alone (a `fired` clause and no external clause), every other shape skipped; the listing leaves the directory out; a **Standing** section after the listing in both renderers, the heading carrying the count, rows numbered within the effort, the blockers cell `external` or `fired` beside any references, `none` when the directory is absent, so the board's shape is constant across trees; the summary line `N open across M efforts and K standing (T tickets read in E efforts)`, standing counted apart from the open tickets and the efforts; the critical path untouched — a release ticket naming a standing ticket shows it, effort-qualified.
