## Changes

- **`gideon preflight` is real** (spec §1.5; slice-0 ticket 03): a two-phase, check-only runner (`gideon/host/preflight.py`). Phase A runs all seventeen provision steps check-only and enforces total convergence — any non-converged disposition refuses with the step's own fix. Phase B runs a new ordered registry of install-time checks (`gideon/host/checks/`): `egress`, `ports`, `hostname`, `ntp`, `ldap`, `backup-ssh`, `smtp`, `free-space`, `jurisdiction`, `hardware-profile`, `driver-tested`, `os-kernel`. Severities are `pass/warn/refuse/inert`; warns and inert lines never block; exit 0 iff no refusal; every refusal prints its fix; nothing halts — the operator sees the whole picture in one run.
- **The versioned egress allowlist lands** (`config/egress.yaml`, spec §2.3 / ADR-0010) with loader `gideon/host/egress.py`: three groups (host-provisioning, install-upgrade, corpus), one probe URL per host, including ticket 02's recorded additions as their real endpoints (registry-1.docker.io + auth.docker.io, cloud-images.ubuntu.com) plus objects.githubusercontent.com. Pre-install runs probe the first two groups plus the site `registry` host (`/v2/`, http iff loopback). Reachability is transport-plus-status: wget `--tries=1 -S`, exit 0 or an 8 whose final HTTP status is 401/404 counts as reached; proxy block pages and 5xx are misses named with their status. `proxy_auth` credentials travel via an ephemeral 0600 wgetrc under `/run` — never argv.
- **Office services exercised for real**: LDAPS simple bind via `ldapsearch` (UPN-qualified bind user, CA-pinned, password by `-y` file) resolving both product groups; SSH to `backup.target` (BatchMode, first-contact enrollment into the fixed `/etc/gideon/backup_known_hosts` that `backup push` will share) with a create-then-remove write probe; one SMTP test message with a fail-closed AUTH posture — credentials are never sent without verified STARTTLS (office CA loaded), and a password file without `alerts.smtp.user` refuses naming the key.
- **Interim inert shape for absent-artifact checks** (ADR-0017 — no invented figures): free-space need, GPU count/model/compute-capability requirements, and jurisdiction court data are injectable seams whose refuse/warn branches are implemented and fixture-tested now, reporting `inert — ships with slice N` until `models.lock`/`courts.yaml`/the corpus lockfile supply them. Judgeable-now warn rows fire today: non-reference profile, driver above tested, kernel vs `kernel_tested`, NTP unsynced.
- **`host-tools` becomes step 17** of provision, converging `ldap-utils` (the bare-host LDAP client preflight shells to).
- **`host.lock` riders**: `driver.tested: "595.91.07"` filled from ticket 02's on-box converge; new nullable `kernel_tested` (fills at this release's on-box preflight evidence).
- **Two new defaulted site keys** (spec gaps (d)/(e) recorded on the ticket): `backup.target.user` (default `gideon-backup`) and `alerts.smtp.user` (default `""`); example file and editor schema regenerated.
- **Spec bugs recorded on the ticket** (never improvised around): (c) ports 443/5000 checked as free **or held by the expected owner** — docker-proxy is resolved to its owning container (`gideon-registry` for 5000, a caddy-named container for 443); (d)/(e) the missing account-name keys above; (f) OS/kernel-drift severity — a different LTS refuses as unsupported platform, within-LTS drift warns.
- **Tests**: 81 new (156 total, 72 subtests) — runner contracts (root/site refusals, Phase A mapping, exit-code truth table, no-halt reporting), per-check truth tables over dict-backed fakes (probe status semantics, proxy-auth secrecy, expected-owner matrix, ldapsearch/ssh/smtp outcome matrices including the STARTTLS downgrade guard, inert/warn/refuse artifact branches), the egress artifact contract, and the updated step-registry/baseline pins.
