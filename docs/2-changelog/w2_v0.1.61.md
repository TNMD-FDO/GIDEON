## Changes

Docker 29 keeps every image, layer, and build-cache entry through the containerd image store, under containerd's own root — `/var/lib/containerd`, on the root filesystem — while the daemon's `data-root`, the one storage value the `docker-engine` step wrote, sits on the 590 GB logical volume the runbook's §1.4 layout sized for Docker and held 12 MB. On 2026-09-09 the store held 160 GB of the box's 196 GB root filesystem and a build filled it (slice-1 ticket 73; ADR-0040). This release makes containerd's root a setting the step owns and moves the box's store once, by hand, in the announced window. The plan is `docs/1-plans/F_0.1.49_containerd-store-fills-the-root-filesystem.plan.md`, its number taken by `main` while the cycle ran and the release renumbered to `0.1.61` before the rebase; the plan file keeps its name.
