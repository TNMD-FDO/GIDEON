## Changes

- **The Filter** (`compose/open-webui/functions/citation_stamp.py`, new): a `Filter` with an `outlet` alone — no inlet, no stream hook, no `Valves`, no toggle, no requirements line, standard-library imports only, none of the four import prefixes the frontend's rewriter replaces. It reads the answer text (the `content`, or the message items' text when that is empty — the frontend's own fallback; never a reasoning item), runs four bounded shape families in a fixed order — `citation/reporter@1` (a volume or blank run, one of thirty-six reporter abbreviations with internal spaces optional, a page or blank; the Federal Register a volume–page cite), `citation/code@1` (`U.S.C.` and its annotated and period-less forms, `C.F.R.`, `U.S.S.G.`, `Tenn. Code Ann.`, with an optional title before and an optional section symbol after, then a section with its letter run, dotted or hyphenated parts, and parenthesised subsections; and the bare symbol, single or double, with a number), `citation/rule@1` (the six federal rules' abbreviations alone or with a number), `citation/database@1` (a year, `WL`, a number; a year, a LEXIS court token, a number) — every repeat bounded and a match ceiling a test holds, and on a hit appends a blank line and §15's sentence to `content` and to the last text part of the last message item, creating that item with the whole stamped answer when the output list has none. An answer already ending with the sentence is left alone, so a second pass never doubles it; a malformed body is returned untouched; the same body object is returned on every path; an internal exception appends the sentence and returns (ruling 4: a false label is harmless, a missing one the failure). The sentence, the guardrail's deadline refusal, and its session refusal each detect as nothing.
- **The seed** (`eval/seed/general/citation-stamp.yaml`, `eval/seed/general/README.md`, new): `family: citation`, `pattern_set_version: 1`, 18 shaped cases each naming the family that must hit (a reporter with a pin, the blank form, a Federal Register cite, a no-space reporter, a Supreme Court cite, a statute with a subsection, a bare section, a C.F.R. cite, a Guidelines cite with and without the space, a code cite without the symbol, a hyphenated state section, a period-less code, a criminal rule with its number, an appellate abbreviation alone, a Westlaw and a LEXIS cite, several shapes at once) and 18 free controls (an everyday rewrite, doctrine naming no authority, numbers-heavy prose, case names without a reporter, the words *Section*, *page*, and *Rule* without a symbol, `Section 3553 of Title 18`, clock times, a version number, `Article II, Section 2`, a form and line, a docket number), every text invented; the README states the shape and the never-edit rule and names ticket 39's smoke set as the directory's next file.
