- **The `sources` check** (`tools/turns/cases.py`, `tools/turns/classify.py`, `tools/turns/run.py`):
  - `Case.sources` is `present`, `absent`, or `any` (the default), read as `block` is. An invalid value is refused naming the case and the field, and a seed case carrying it is refused.
  - `Verdict.sources_present` is true iff the stored assistant message's `sources` is a non-empty list.
  - `case_checks` adds a `sources` result, and `judge_case`'s detail gains `sources <present|absent>`, only when a case names one. Every existing row's text is byte-identical.
  - The records gain `case.search`, `case.sources`, and `verdict.sources_present`. The browser mode judges through the same call and needed no change.
- **Retirement in a cases file** (`tools/turns/cases.py`): `supersedes:` is read as the seed reads it. An unknown target or a non-string is refused with the seed's message, and the superseded cases are dropped from the loaded set but kept in the file. The origin appends ` (M superseded)` only when M > 0, and `searched` is counted over the retained cases.
- **The set** (`eval/seed/general/smoke.yaml`): `doctrine-01`, `doctrine-02`, `plain-01`, `identity-01`, `compute-01`, `compute-02`, `confirm-01`, `citation-01`, `verify-01`, `matter-01`, and `search-01`.

  - `search-01` is the one searched case, asserting `sources: present`, and `plain-01` asserts `sources: absent`.
