## Changes

- **The mode** (`--browser` on `tools/turns`; §18.1, §16, §4.1, ADR-0035): the same per-case loop behind a second turn driver. `run.py` gained the driver seam (`TurnDriver`: `signin`, `observe`, `turn`, `account`) with the API driver wrapping the existing steps unchanged and the browser driver over `browser.py`; `BrowserSetup` carries what the launcher made (the page, its teardown, the request log, the page bound). The mode runs from the dev venv's interpreter (`sudo .venv/bin/python -m tools.turns --browser <cases> --out <dir>`), never the box's system Python; `--out` is required; `--stream` is refused with it.
- **The launcher and the footprint** (`chromium.py`): the pin `PLAYWRIGHT_VERSION` (1.62.0, Chromium 151.0.7922.34) is the pin's one home; Playwright is imported inside `launch` alone (the types under the typing guard), and an AST tripwire holds every other module of the package to the standard library.
