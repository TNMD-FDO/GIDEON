## Changes

- **The ceiling.** A GIDEON block — the marked edit inside a vendored skill — is at most 1,500 bytes between its marker lines, counted as the UTF-8 bytes from the byte after the begin marker's line ending to the first byte of the end marker line. The number lives once, on a machine-readable `Ceiling:` line in `docs/agents/tooling.md` §4 whose paragraph states the rule, the count, and the value's correction under ADR-0017 (the round number above the largest block that stayed inline, `archi-map-update` at 1,149, and below the smallest that moved, `on-box-staged-proof` at 2,611). Over it, a block carries a summary and a pointer, and the prose lives whole in a document under `docs/agents/` — which no upgrade touches, which `/writing-for-agents` is the instrument for, and which a reader finds without opening a vendored skill.
- **The tripwire** (`tests/test_skills_vendored.py`, rule `i`): every block in every file of every lock entry measured through the one marker scanner rule `c` uses; a block over the ceiling is a finding naming the file, the id, its bytes, the ceiling, and the fix (move the prose, leave the summary and the pointer); a missing or unparsable ceiling line is a record finding on the tooling document, never a default. Two mutation subtests prove it — the first table row's block grown past the ceiling, the line broken — and the committed tree is asserted clean. The module states no version and no number.
- **`docs/agents/on-box-proofs.md`.** The five on-box rules of `TRIP-2-implement` — the long child after heavy on-box streaming run detached and waited on in the foreground, the secret reaching a command by file or stdin only, the turn harness for a Filter ticket's turns and its browser mode for a users seat, the bounded hand-run child, the harness-stage criterion proven over a temporary ref of the staged index — moved whole, each section opening with its rule, carrying its command shapes byte-identical, and ending with the release that taught it. The five marker pairs become one, `on-box-proofs`, 727 bytes at the same anchor, naming the document and each trigger.
