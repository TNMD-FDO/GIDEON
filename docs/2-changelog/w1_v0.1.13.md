## Changes

- **The default model, one rendered value** (`gideon/host/render/owui.py`; §15, [06] item 2, §3.5, ADR-0028, ADR-0035): `owui_environment`'s connected block gains `DEFAULT_MODELS` = `GENERAL_PRESET_ID` beside the task model — a GPU host with the engine, where General's record exists; the no-GPU host and the drill's disconnected frontend carry none. On the pinned frontend the value is a raw comma-separated id string served as `default_models` to a signed-in caller and split client-side, and a new chat takes it after a `?model=` parameter, a folder's pins, the tab's carry-over, and the user's own "Set as default", and before the first-visible-model fallback; every branch but the parameter one skips a hidden model (`docs/research/owui-default-model-and-arena.md` §1). With one visible model per role the rendered value and the fallback agree, so the value is proven by the served config and by the panel-edit reversion, and earns its keep when a second branch is visible.
- **The evaluation arena off, on every host** (`ENABLE_EVALUATION_ARENA_MODELS=false` in the base environment; discovery ruling 1; ADR-0017 `exempt: policy toggles`; ticket 29's fourth item and [06]'s item (d)): the pinned frontend's arena is on by default and offered to admins alone (its one hardcoded entry carries no grant), and an arena turn draws a model at random from the process-wide cache with no access or hidden check — on this box General or the hidden base model, so an admin's arena turn could have answered from the bare generator with no system prompt, indistinguishable from General until the reveal (the note's §4). Off removes the entry for every role; the Admin → Evaluations page and the panel's toggle stay.
- **The two riders, on the same manifest**: `chat.web_upload: false` in `compose/open-webui/permissions.yaml` with its source comment (ticket 28's ruling: §15's warned-egress-only and no-upload posture, [22]'s content-free logs), rendered as the environment default and into every group's manifest permissions and pushed back on a drift; and `GENERAL_SUGGESTION_PROMPTS`, empty, rendered as `meta.suggestion_prompts: []` on General's record (ticket 30's ruling: the record is the one lever, since the frontend replaces an empty frontend-wide list with its stock six at boot). `meta.profile_image_url` stays unset; the base model's record is unchanged.
- **Panel edits of environment-borne facts, the semantics recorded** (discovery ruling 3): at v0.11.3 the frontend's config is a per-key model, not the older single-blob class; under `ENABLE_PERSISTENT_CONFIG=false` a read never touches the database and a panel write goes into the process's in-memory defaults and nowhere else — live for every later read, gone when the container next starts (the note's §2). Apply recreates the frontend only when a frontend-owned file changed, so a no-change apply leaves such an edit standing until the next restart: §3.5's "evaporate at the next restart or apply" read exactly, recorded on ticket 08 and in ARCHI §15, not changed.
- **Tests and fixtures** (`tests/test_render_owui.py`, `tests/test_render.py`, `tests/test_owui.py`): the identity-and-policy test pins the default model and the arena flag and the connected-only name set gains `DEFAULT_MODELS`; the disconnected shapes carry no default and the flag false; the permission test pins the leaf by name; the manifest test holds General's `meta` with the empty list and every group's leaf false; the drill test holds the two environment facts; the engine-service test holds the frontend's default to General's id; one swallowed-failure case over a hand-added suggestion list refuses naming `gideon-general` and the field and never a text. Nine fixture files regenerated — `compose.yaml` and `open-webui/manifest.yaml` in all three sets and each set's render manifest — and nothing else.
- **The contract module** (`tests/contract/compose.yaml`, `tests/contract/owui_apply_manifest.py`): the stack's compose carries `DEFAULT_MODELS` from the release's constant through the harness's `.env` (as the allowed endpoints ride) and the arena flag false; the model-state assertion holds General's `suggestion_prompts` to `[]` and every group's `chat.web_upload` to false; the hand-edit step adds a one-entry list to General and flips the users group's leaf through the group update route, and the second push restores both and names the group in `updated_groups`; a new session-only method holds the served `default_models` to the rendered value and the admin's chat-facing list empty, makes the panel's default-model and arena edits through the frontend's own config routes and reads them standing, restarts the stack's frontend, and reads the rendered values back.
