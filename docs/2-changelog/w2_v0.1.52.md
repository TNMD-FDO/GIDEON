- **The marker and the text loader** (`gideon/host/site.py`; the plan's Implementation Details 1): `FieldSpec.office_value`, default off, set through `_field` on the sixteen leaves whose value locates or names a machine, a network, a directory object, a mailbox, or an account — `hostname`, `lan_cidrs`, the directory host, the search base (spelled or derived, the configuration holding it in one field), the bind user, the three group leaves, the backup target's host and account, the relay's host, sender, and account, the recipients, the registry, and the egress proxy — and on neither the office's identity, the jurisdiction, nor the backup path; the schema emitter reads named attributes, so `config/site.schema.json` stands byte for byte. `parse_site_text` and `load_site_text` split the parse-validate-construct chain from the file read, so a rendered document loads from its text through the same pipeline; `GROUP_PATHS` and `parse_group_dn` are public, since the tool reads them.
