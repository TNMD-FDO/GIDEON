## Changes

This release implements slice-2 ticket 08 under the plan `docs/1-plans/the-grading-kit.plan.md`: the tools an attorney's eight to ten hours pass through (§18.4(a), [21] items 7 and 13), built and proven over an invented fixture before the hours are asked for. A pool file goes in, a folder of blind HTML packets comes out per grader, the small plain-text grades files come back, and the judgments file accumulates with κ over the double-graded tenth. Nothing here touches the box; a patch, as the plan's Overview said: no site key, no `/etc/gideon` contract change, no image change, so `images.lock` is untouched. The judgments file's shape lands as a product module now; its loader is ticket 09's by the maintainer's ruling.

- **The judgments file's shape** (`gideon/evaluation/judgments.py`, new — the product module, standard library alone per ADR-0046): the file's relative name under a set root, the line's closed ordered keys — `query_id`, `source_id`, `sha256`, `start`, `end`, `grade`, `grader`, `assessment` — each field's rule, the file-level rules (a (query, coordinates, grader) triple once, at most one `primary` and one `second` per (query, coordinates), a final newline), the one serializer, a reader returning every finding at once, and the agreement computation. **A grade is keyed to gold-evidence coordinates and never to a chunk id**, because Phase A's E11 re-chunks the corpus and a chunk-keyed grade would not survive it; `end − start` equal to the text's length in **code points** ([21] Q9) is the one integrity check possible without the CAS. `assessment` is the plan's one addition to the ticket's field list: ticket 09 needs to know which grade counts, and the alternative — "the earlier line in the file" — would have made intake order meaningful. `evalset.py` exposes its role and judgments-id patterns under public names, one home per pattern and no copy; nothing else in the loader changed.

- **The packet builder** (`tools/judgments/packets.py` and two templates, new): stages `queries`, `pool`, `assign`, `write`, then the summary. **The output is a pure function** of the pool's bytes, the queries file, the sorted roster, and the templates — no clock, no random source, no absolute path — so two builds are byte-identical and a shuffled pool yields the same bytes as an ordered one. **Blindness is structural, not polite**: a pool passage's optional `provenance` object is validated as an object and never read into, so there is no code path from a score, a rank, or a leg name to a rendered page; the test plants all three as sentinels and finds them in no output file. A query's passages are ordered by the SHA-256 of the query id and the passage's coordinates, so the order carries no signal and both readers of a double-graded query see one order. The deal is an even split of the queries that have a pool, `chu-written` queries routed first to the CHU attorneys and the overflow reported by count, with the double-graded ⌈n ∕ 10⌉ drawn on a **second, differently salted** hash so the draw is independent of the deal. A roster is attorney role ids only, at least one CHU and one TRAD, flag order immaterial.

- **The packet digest binds what the reader saw**: SHA-256 over a canonical payload of the packet format number, the query id, the grader, the assessment, the question, and per passage in display order its coordinates, caption, and text. A changed question, caption, passage, order, assessment, or page format moves the digest, so a stale grades file is **refused by name rather than misjoined** — the silent-corruption case, where a rebuilt packet's ordinal 7 is a different passage and the returned file is still well-formed. A rebuild that changes nothing a reader saw keeps every digest and grades already in hand stay good. The test holds both halves: the digest moves for each bound element, and by nothing else. A digest reveals nothing of the text under it, so it rides the grades file's header line.

- **The grades intake** (`tools/judgments/grades.py`, new): reads the manifest and the returned files, joins ordinals to coordinates through the manifest, validates every new line and the resulting file through the product module, appends atomically (the questions intake's sibling-temporary-file pattern), and prints a row per packet, the summary, and the κ lines; `--dry-run` prints the same and writes nothing. It is all or nothing over one run's files, any refusal appending nothing and exiting 1, and **it never opens a file holding a question or a passage**. Refusals name a packet by query id and role id and, within it, ordinals and grades only.

- **κ, both numbers** (ADR-0023: reported and paired, never gated): unweighted Cohen's κ over the four grades, and κ with grades collapsed at relevant = grade ≥ 2 — recall@50's line, ticket 09's. Two numbers because the gap between them is diagnostic: ten pairs whose misses are one step on the same side of the line give four-grade 4⁄9 and collapsed 1 (the scale's wording is fuzzy, the judgment sound), while ten pairs whose misses cross it give 4⁄9 and 1⁄6 (the graders disagree about relevance itself). Both tables are hand-computed in the test's own comments. With no pair, or no variation — expected agreement of one, where κ is undefined rather than perfect — the line says so in words and prints no number.

- **Content discipline** (§19.4): both commands print ids, role ids, ordinals, counts, and digests, never a question, a caption, a passage, or a `provenance` value; an unexpected exception is `internal error (<class name>)`, its message withheld because a message can quote input. The Codex review's one major finding was exactly here — three refusal paths could echo arbitrary input text — and was corrected and regression-tested before the verdict.

- **The tests**: `tests/test_evaluation_judgments.py` (new, kept) holds the exact ordered key tuple so a `text`, `question`, `quote`, or `name` key is refused, each field's refusals including a boolean as an integer, the attorney pattern a subset of the loader's role pattern, the file rules, serialize-then-read byte stability, findings carrying no value, and the two κ tables with the no-pair and no-variation states. `tests/test_judgments_kit.py` (new, excluded) runs over temporary roots with an invented pool: determinism and the shuffle, the `provenance` and text sentinels, the page with no external reference, the deal and the tenth and the second-reader rule in both cases, the digest's bound elements, every refusal with its fix, all or nothing, the dry run, and the full round trip against the hand-computed κ. `tools/exportboundary.py` and `.gitattributes` gain the excluded test's entry.
