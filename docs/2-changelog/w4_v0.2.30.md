## Changes

This release implements slice-2 ticket 24 under the plan `docs/1-plans/the-sign-off-kit.plan.md`, spec §18.4(b), §18.6, §19.4, §2.6, and §0.2's supersede rule, [21] items 7b and 16, and the maintainer's four rulings at the claim. `v0.2.28` left every `research-qa` case unsigned and nothing an attorney could open or mark; this builds what turns an unsigned case into a signed one, and proves the round trip without committing a byte of it. Nothing is applied on the box and no `gideon` command, flag, or `STUBS` entry moves.

- **Drafts in, packets out** (`python3 -m tools.signoffs.packets <drafts file> --out <dir> --signer <role id> [--signer <role id> …]`; `tools/signoffs/packets.py` and `templates/packet.html`, new). Stages as rows: `set` (the loader over the checkout's set root, its `unsigned_ids` and case questions the only things read from it), `drafts` (a JSONL file kept **outside the checkout** giving each case a drafted expected answer, the authorities it must cite, and the passage it rests on, checked whole — a signed, superseded, or undrafted case reported by id and skipped, nothing to sign refused), `assign` (ruling (b): the roster sorted, the drafted unsigned cases in case-id-hash order dealt round-robin — no CHU routing and no second reader, unlike the grading kit's draw; more signers than cases refused with the count), `write` (one page per signer and `manifest.json`), then the summary. The output is a pure function of the drafts' bytes, the set, the sorted roster, and the template — no clock, no random source, no absolute path — so a shuffled drafts file yields byte-identical pages.
- **One page per attorney, ruled at the claim** (ruling (a), over one page per case and over plain-text sheets). Each of that attorney's cases is a section: the question, the drafted answer, the authorities by caption, the passage, an Accept button and a one-sentence Correct box, with a marked-of-total count and a Save control writing `signoffs-<role id>.txt` whose header carries the packet digest's prefix and the date the page reads from the device at the save. The page is self-contained — no external reference, every value HTML-escaped, storage access guarded — and its `<noscript>` block prints the header line to copy and the two mark forms, so a workstation without script is still served. The **checkpoint** in the plan's to-dos put a built fixture packet in front of the maintainer to open and mark before the intake was built on its marks file; the packet's faults are usability faults no unit test sees.
- **Sign-offs in** (`python3 -m tools.signoffs.intake <manifest> <marks file> [<marks file> …] [--dry-run]`; `tools/signoffs/intake.py`, new). Every packet's digest is recomputed from its manifest fields and held equal to the stored one **before any row**, so a manifest edited after the build refuses the run rather than signing what no one read. Then the set, then each marks file as one unit outcome, then the relational pass — each case active, unsigned, and not signed twice within the run — then the records ordered by case id, each validated through `gideon/evaluation/signoffs.py` and the whole file re-parsed, appended atomically. All or nothing over a run: any refusal prints the summary, writes nothing, and exits 1, so a fixed file is re-run whole. A correction's sentence becomes `expected.answer` and the draft's `must_cite` stands (ruling (c)); a disputed authority is a re-draft on the next drafts file, never a `cite:` line the intake would have to parse.
- **The digest is what makes a returned file trustworthy.** It binds the format number, the role id, the display order, and each case's question, answer, must-cite ids and captions, and passage text and coordinates — everything the reader saw — and nothing else, `provenance` among the unbound, so a rebuild that shuffles the drafts file keeps every digest and returned marks stay good, while anything a reader saw changing refuses the stale file by name. The test moves each bound element in turn and asserts the digest moves, and moves the unbound ones and asserts it does not; a separate case mutates **every write-bound manifest field** — an answer, a must-cite id or caption, a coordinate, a hash, the stored digest itself — and holds each refused before any row.
- **Blind on both sides.** The manifest carries no question and no passage text, and the intake opens neither the cases file nor the drafts file: it reads the manifest and the marks files alone. Refusals name a packet by role id and, within it, case ids and line numbers — never a marks file's name and never a header that is not ids, so a mistyped header is not echoed back. The test plants sentinels in the questions, answers, captions, and passage text and asserts each appears only where it is declared to and nowhere in any stream.
- **The grading kit's helpers made public, not copied** (`tools/judgments/packets.py`, `grades.py`). The template parser splits into a public function taking a template path and the cached name-taking wrapper over the grading kit's own directory; the substitution, the paragraph escaper, and the two guards lose their underscores with their call sites renamed and their behaviour unchanged. The atomic append splits into a public function that **raises `OSError`** and the wrapper that turns it into the grades refusal — the code review's one Major finding, raised because the first shape converted the write error to `GradesError`, which the sign-off intake catches as `OSError` and would have reported as an internal error instead of an actionable write refusal. Both sides of the boundary now have their own refusal and their own regression case.
- **Nothing is committed, deliberately.** The kit's one committed product is `research-qa/signoffs.jsonl`, and this cycle writes none: the whole round trip runs in temporary roots. Packets, the manifest, and marks files hold questions and answers and are built outside the tree — an `--out` inside the checkout or not empty is refused, as is a drafts file inside it. So the sign-offs file's byte pin and boundary entry are still owed, and the two `NOTES.md` lines that carried that debt keep their facts and move their trigger from "ticket 24's kit" to slice 3's first real intake, the kit now existing and still committing nothing. The same is true of the fourth export-blind test that passes vacuously: it needs a signed case in the tree, which no kit can supply.
